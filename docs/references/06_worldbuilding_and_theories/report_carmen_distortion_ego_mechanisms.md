# 都市世界观参考：卡门、扭曲、罪种与 E.G.O

依据[灰机世界观专题](https://limbuscompany.huijiwiki.com/wiki/世界观/罪种、扭曲与E.G.O)、[E.G.O条目](https://limbuscompany.huijiwiki.com/wiki/E.G.O)及本地剧情，区分角色认知、机制说明和哲学解读。灰机的概括不自动成为适用于所有角色的必要充分条件。

## 1. 光之种与白夜、黑昼

脑叶公司、光之种与后续扭曲现象有关联；事件用名可对照 `StoryData/S707B.json` `id=41` 的“白夜与黑昼”。旧稿的“在第七日遭破坏中断”“百万年轮回”未附可复核位置，不能作为精确时间线使用；具体计划长度、发射持续时间和黑暗时长需分别取证。

## 2. E.G.O 与扭曲不能写成善恶二选一

- 区分从异想体提取／共鸣使用的 E.G.O 与个人绽放 E.G.O；巴士释放一次 E.G.O 技能不等于剧情中刚完成自我觉醒。
- 卡门的声音与扭曲有关，但不能把“听到声音即必然变成无理性怪物”写成统一公式；也不能将所有绽放都写成当事人受到艾因直接指引。
- 工作区 `StoryTheaterDanteNoteDetail_13.json` 的 `DanteNoteDetail_178`（“绽放E.G.O”）强调信念未必是正确或善良的，不稳定者仍可能扭曲；不能用“勇敢负责=必然觉醒”的道德判据代替剧情。原稿的“卡门蛊惑／艾因坚守”只可作为解释性对照，不是完整机制。

## 3. 可定位条目

| 对象 | 当前可支持的表述 | 证据与范围 |
| --- | --- | --- |
| 独石 | 可强行诱发或增幅扭曲的黑色石碑 | `StoryTheaterDanteNoteDetail_6.json` `DanteNoteDetail_105/107`；与金枝的感受比较和装置猜测须保留但丁语气，不补T公司已批量收集之说 |
| 罪种 | 有后续角色明确说明其为未能成为扭曲的个体 | 早期 `DanteNoteDetail_99` 是辛克莱和但丁的推测；后续 `StoryData/E706B.json` `id=6` 霍恩海姆明确说明，韩文 `죄종은 뒤틀림조차 되지 못한 개체일세`；再见 `DanteNoteDetail_129`。不能只引用早期记录就断言截至当前仍没有确认依据 |

| 金枝 | 与情感共鸣、扭曲相关；新剧情中被用作巨人空位的应急替代 | `DanteNoteDetail_105/107` 及 `RPGSystem/rpg-loc-dialogue-floor-4.json` `D40220/13`；“总部核心残片”的具体物质来源本轮未取得足够依据 |

## 4. 第十章研究接口

[剧情工作台2.3与2.6](../../../STORY_NOTES.md)保留卡门、阳光、巨人、完人及意识世界的用户和社区猜想，并列出已译文本和韩文位置。金枝代替工作座位、物品描述阳光低语有证据；“低语一定是卡门”“卡门就是赤神”“N公司为治疗都市病而创立”尚不能靠这些条目直接推出。文学与哲学类比仍保留为后续翻译参考。
