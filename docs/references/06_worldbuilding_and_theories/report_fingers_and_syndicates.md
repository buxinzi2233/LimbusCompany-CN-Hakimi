# 都市世界观深度考据研报：五指黑道教条与后巷地下生态

## 1. 概念界定：手指（The Fingers）

在都市无序的后巷生态中，**“手指”（Fingers）** 是后巷具有广泛影响的五大帮派势力。五指各自拥有独立的严苛教条与武装体系，其权威在后巷堪比大翼。
依据但丁笔记及[灰机五指](https://limbuscompany.huijiwiki.com/wiki/世界观/五指)，五指中文名称为：**拇指、食指、中指、环指、小指**（切勿将 Ring 错译为“戒指”或“指环”，零协会统一规范定名为“环指”）。

---

## 2. 五指各自核心教条与运作模式（官方设定对照）

### 2.1 拇指（Thumb）
- **核心教条**：极致的阶级秩序与尊卑礼节。下位者对上位者必须使用绝对敬语，违者当场处决；
- **组织结构**：教父、二老板、指挥官、士兵（[灰机五指](https://limbuscompany.huijiwiki.com/wiki/世界观/五指)；不以外语音译替代已有中文职称）；
- **武装特征**：精密的枪械与特制弹药配给体系，刺刀格斗与重度枪火压制。

### 2.2 食指（Index）
- **核心教条**：盲从天意指令。所有人必须无条件执行由“织机”纺出的绢帛指令，无论指令内容如何荒谬残忍；
- **组织结构**：纺织者、传令员、代行者、苦行者（见灰机五指）；
- **哲学机制**：将个人意志彻底抹杀，视指令为都市运行不可违抗的神圣因果律。

### 2.3 中指（Middle）
- **核心教条**：极端病态的“家庭”纽带与复仇执念。成员间互称大哥、大姐、小弟、弟妹；
- **核心道具**：**复仇账簿**。任何对中指成员的微小侵害（甚至如偷窃理发券），都会被记录在账簿上，招致被追讨复仇的后果（不把夸张倍数当固定制度）；
- **实机印证**：在第五章U公司大湖及后巷中，大批中指成员追击至东部，极度重视家族血性。

### 2.4 环指（Ring）
- **核心教条**：围绕艺术活动形成不同流派。将人体组织、神经痛觉与异化改造视为前卫艺术作品；
- **组织结构**：大师（Maestro）、讲解员（Docent）、学徒；中文基准 `Personalities.json` 的 `10915.title` 为讲解员，`10109/10515.title` 为学徒，不得混为一级；
- **实机印证**：在后巷建立艺术走廊，进行耸人听闻的人体活体艺术创作。

### 2.5 小指（Pinky）
- **笔记记载**：重视“仁”，但但丁尚不清楚其具体含义；成员隐藏身份在其他组织活动，未被召集时甚至不知道彼此身份。
- **来源与边界**：`references/baseline-zh-CN/StoryTheaterDanteNoteDetail_11.json` 的 `DanteNoteDetail_150`；原文保留未知，不据此补写情报交易或契约暗杀职能。

## 3. 关联后巷帮派势力

1. **剑契组（Blade Lineage）**：追求极致剑术大义的刀剑流派，与黑云会存在冲突，具体关系按所在地区和剧情核对；
2. **黑云会（Kurokumo Clan）**：拇指的附属帮派，擅长墨黑刀法与流血折磨；
3. **圣愚（Yurodivy）**：由索尼亚创立、在J公司后巷及T公司蔓延的底层反抗组织，自诩为都市受苦者的代言人；
4. **清道夫（Sweepers）**：每日后巷深宵（凌晨3:13~4:34，来源为[游戏官网](https://limbuscompany.com/)；但丁笔记 `DanteNoteDetail_147` 则记为 3:13 开始、持续 80 分钟，两种时长表述不强行合并）出动的液体燃料回收者，吞食一切尸体与残余生命。
