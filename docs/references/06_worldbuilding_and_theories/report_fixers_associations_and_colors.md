# 都市世界观深度考据研报：收尾人等级、十二协会与特色收尾人谱系

## 1. 收尾人阶位制度（1阶至9阶）

在都市中，收尾人（Fixer）是持有收尾人执照、承接各类调查、护卫、暗杀与清理委托的雇佣专家。
- **阶位划分**：严格按照 **1阶（最高）至 9阶（最低）** 进行划分（本库采用“阶”，切勿写作“级”）；
- **考核晋升**：由하나协会统筹阶位、执照及事务所相关事务；[灰机하나协会](https://limbuscompany.huijiwiki.com/wiki/世界观/하나协会)区分协会直接考试与向总协会报备，不推定各阶位必有特权或固定阵亡率。

## 3. 特色收尾人（Color Fixers）参考

特色由하나协会授予色彩称号；并非独立的“0阶”。对颜色象征的解释不能替代资格说明，笔记 `DanteNoteDetail_161` 还保留了各种猜测。下列为既有资料线索，不是完备名录：

1. **猩红视线（The Red Gaze · 维吉利乌斯）**：
   - 边狱公司引路人，手持猩红短剑，具备瞬间歼灭大群精锐的绝对压制力（个人称号官方定名为 **“猩红视线”**，严禁错写为“红色视线”）；
2. **靛蓝老人（The Indigo Elder）**：
   - 纵横 U 公司大湖的传奇捕鲸人，驾驶以 X 公司合金打造的捕鲸船，以一发巨型捕鲸枪独自猎杀大湖海怪；
3. **蜜黄标枪（노란작살 / The Amber Harpoon）**：
   - 官方但丁笔记（`StoryTheaterDanteNoteDetail_11`）明文确证的特色收尾人之一（“猩红视线、靛蓝老人、蜜黄标枪……我们已经与三位特色并肩作战过了”），切勿主观臆造为“黄色长矛”或“黄色标枪”；
4. **殷红迷雾（The Red Mist · 卡莉）**：
   - 脑叶公司传奇守护者，以强大战力知名的收尾人，边狱公司语料库官方译名统一为 **“殷红迷雾”**；
5. **漆黑噤默（The Black Silence · 罗兰 / 安吉丽卡）**：
   - 擅长全套工坊致命冷热兵器连续袭杀的传奇特色；
6. **苍蓝残响（The Blue Reverberation · 阿尔加利亚）**：
   - 扭曲乐团的引导者，挥舞战镰的悲剧特色；
7. **堇紫泪滴（The Purple Tear · 伊织）**：
   - 掌握维度穿梭与空间切裂技巧的次元漫游者；
8. **朱红十字（The Vermilion Cross）**：
   - 原都市知名特色，后在废墟与异象中阵亡。

## 4. 来源与使用边界

协会功能可对照[灰机但丁笔记](https://limbuscompany.huijiwiki.com/wiki/但丁笔记)，中文名称按零协会基准同 ID 使用；区域分科的人格装备不能推广成整个协会的统一设计。하나／Tres分别负责收尾人统筹与工坊装备管理，不负责本表旧稿所称的所有大翼专利认证。

特色译名依据：[猩红视线](https://www.zeroasso.top/archive/name/red-gaze/)、[蜜黄标枪](https://www.zeroasso.top/archive/name/amber-harpoon/)，以及[灰机维吉里乌斯](https://limbuscompany.huijiwiki.com/wiki/维吉里乌斯)中的堇紫泪滴。前作角色履历仍需按《废墟图书馆》《利维坦》等原作位置定位，本文不保留“战力天花板”“必然一击歼灭”等无边界断言。
