# 都市世界观深度考据研报：译名依据与本地约定

## 1. 角色人名与代称争议

### 1.1 罗佳（Rodion / Rodya）
- **争议焦点**：是否应全篇统一翻译为全名“罗季昂”。
- **零协会定名标准**：人物常用名采用“罗佳”；具体全名、昵称和称呼需按原文与同 ID 基准，不凭“场合严肃”自行替换。原稿的全篇分配规则未定位为零协会明文。

### 1.2 良秀四字断句缩写
- **争议焦点**：良秀说话口癖的符号连接形式（空格 vs 连字号 vs 中圆点）。
- **零协会定名标准**：可使用间隔号 `·` 处理缩写，具体依[罪人语言风格](https://www.zeroasso.top/docs/translate/sinnerstyle/)及原文；`·` 是 U+00B7，不是所谓“全角中圆点”。示例须另查实际 ID，不能宣称这种标点能够保证解决所有 TMP 排版问题。

## 2. 特色与指系专有名词

### 2.1 猩红视线 vs 红色视线
- **争议焦点**：部分民间讨论常简称为“红色视线”。
- **零协会定名标准**：实机解包 `Personalities.json`（ID: 9999）与 `Passives.json`（ID: 999901）中明文定名为 **“猩红视线”**。作为专有色彩称号，严禁私自降格为通用词“红色视线”。

### 2.2 环指 vs 戒指 / 指环
- **争议焦点**：英语 The Ring 早期常被民间直译为“戒指”或“指环会”。
- **零协会定名标准**：韩语原文为 약지（环指，见 `StoryTheaterDanteNote_10.json` 的 `TheRings`），但在都市五指体系中（拇、食、中、环、小指），零协会官方定名严格确认为 **“环指”**（见 `StoryTheaterDanteNote_10`，对应解剖学无名指/环指）。民间称其为“戒指”属于脱离五指解剖学体系的非正规民间称谓。

### 2.3 蜜黄标枪 vs 黄色标枪 / 黄矛
- **争议焦点**：韩文原文特色称号 `노란작살`（The Amber Harpoon）的定名。
- **零协会定名标准**：中文基准但丁笔记（`StoryTheaterDanteNoteDetail_11`，`DanteNoteDetail_161`）明确确认为 **“蜜黄标枪”**（“猩红视线、靛蓝老人、蜜黄标枪……我们已经与三位特色并肩作战过了”），严禁使用民间直译的“黄色标枪”或“黄色长矛”。

## 3. 核心机制与剧情事件

### 3.1 清除凯茜（Clear All Cathy）
- **零协会定名标准**：严格定名为 **“清除凯茜”**。此定名既呼应计算机底层代码 `Clear All` 的彻底抹除指令，又契合第六章结尾游戏 UI 与剧情文本被逐字清空的震撼实机演出。

### 3.2 动词三元组法则
- **本地门禁约定**：工作区 AGENTS.md 的动词要求仍按项目约定执行，不能冒称零协会完整规范或世界观公理；零协会[技能规范](https://www.zeroasso.top/docs/translate/skills/)另区分施加／获得的动作主体、强度／层数及其变化，翻译必须读韩文实际机制。
