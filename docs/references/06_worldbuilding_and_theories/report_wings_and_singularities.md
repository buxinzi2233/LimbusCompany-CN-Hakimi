# 都市世界观参考：翼、已知技术与奇点的证据边界

本文以[灰机世界观](https://limbuscompany.huijiwiki.com/wiki/世界观)、[零协会文档](https://www.zeroasso.top/docs/main/)和本地但丁笔记为基准。灰机明确提示包含编辑者推测，引用时保留其“未知／推测”；公司业务、产品、执行机构不自动等于奇点。下面保留原报告涉及的17项，不为未查明的技术补造原理。

## 1. 基础概念

都市按26个区组织，翼与巢、后巷需区别；折翼后的空缺和旧、新同字母公司也须分开。巢有自身规则与准入条件，不能由“巢”一词保证所有居民富裕安全。[灰机12区](https://limbuscompany.huijiwiki.com/wiki/世界观/12区)特别记载脑叶公司折翼后该巢的混乱。

后巷深宵：官网区间3:13–4:34与但丁笔记 `DanteNoteDetail_147` 所述3:13开始、持续80分钟存在表述差别，分别保留，详见[五指与后巷](report_fingers_and_syndicates.md)。奇点可涉及残酷代价，但“所有／多数奇点必然以人体转化维持”不是本表能够证明的普遍规律。

## 3. 历史与制度关联的使用边界

- 烟霾战争、旧L倒台及后继脑叶公司，应与脑叶后来折翼分别叙述；不要把旧L与脑叶当作同时存在的同一实体。
- 概念焚化炉、技术被销毁与发明者经历，应逐个定位但丁笔记及第四章文本；不能从“东朗的技术被销毁”推成“首脑和所有翼共同运营同一设施”。
- 光之种、白夜与黑昼、扭曲与E.G.O的讨论见[机制参考](report_carmen_distortion_ego_mechanisms.md)。原报告的消费、剥削和主体性分析可作为研究方向，但不能替代技术和历史证据。
