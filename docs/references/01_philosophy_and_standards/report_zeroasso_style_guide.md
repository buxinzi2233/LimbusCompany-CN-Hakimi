# 都市零协会本地化研报：多模态语域分化翻译风格深度指南 (LLC Multi-Register Style Guide)

## 1. 理论根基：什么是“零协会风格”（LLC Style）？

民间汉化组织“都市零协会”（Localize Limbus Company, LLC）在长达数年的本地化实践中，确立了独特的汉化美学与工程规范。这种风格并非译者随性的文字游戏，而是一套**高度自洽、在克制与张力之间取得严谨平衡的多模态语域分化系统**。

其核心精神可以概括为三原则：
1. **真实语义第一性（Semantic Fidelity First / “信”字当先）**：
   汉化的首要任务是精准无损地传递月亮计划（Project Moon）编剧团队与总监金智勋的原意，坚决抵制任何脱离原作设定的“二次创作”或“加戏式意译”。
2. **语域高度分化（Functional Register Stratification）**：
   严禁将一种文风生搬硬套到全游戏。文学叙事追求留白沉浸，机制文本追求工业级严密，异想体记录追求临床病理冷峻，系统 UI 追求极简高效。
3. **都市异质感捍卫（Defense of City Otherness / 坚决异化）**：
   脑叶世界观下的“都市”是一个充满后冷战赛博朋克资本异化、近代东亚战后创伤与西方存在主义荒谬感的虚构舞台。译文严禁使用中国本土仙侠修真词汇（如“道友”、“渡劫”、“元神”）、古代官场用语或当代网络烂梗，必须捍卫冰冷、压抑且带有机械质感的“月计味”。

---

## 2. 四大多模态语域分化规范 (The Four Distinct Registers)

```text
                                 ┌─── 语域一：主线文学叙事 (Narrative Literature) ─── 克制留白、原著互文、角色文风指纹
                                 ├─── 语域二：战斗技能与机制 (Combat & Mechanics)   ─── 工业化公式、动词三元组、关键词空格
都市零协会全语域本地化架构 ──────┼─── 语域三：E.G.O与异想体 (Abnormality & Lore) ─── 临床解剖口吻、SCP式学术观察、意识流
                                 └─── 语域四：系统UI与交互 (System UX & UI)       ─── 极简利落、紧凑防溢出、符合中文交互直觉
```

### 2.1 语域一：主线文学叙事（Narrative Literature）

主线剧情（`StoryData/`）是《边狱公司》的灵魂。每位罪人均承载一部世界文学巨著的母题，叙事翻译必须做到文学对齐与口吻严苛分化。

#### (1) 拒绝“中文信息熵增”（严禁自嗨成语化）
- **现象剖析**：许多非专业译者在翻译韩文短句时，盲目追求中文“四字成语”或华丽辞藻，殊不知成语往往带有强烈的特定文化成见与情感饱和度，容易将金智勋独特的“平实残酷”、“无声留白”破坏殆尽。
- **正反案例对比**：
  - **韩文原文**：그는 아무 말도 하지 않고, 그저 나를 바라보았다.
  - **错误意译（自嗨）**：他默然伫立，神情若有所思，饱含深意地凝视着我。（擅自增加“神情若有所思”、“饱含深意”等脑补信息）
  - **零协会标准译**：他一言不发，只是注视着我。（平实、留白、如刀般客观，完全契合加缪式的局外人笔调）

#### (2) 角色独立文风指纹（Voiceprints）
- 剧情对话中绝对禁止“千人一面”。译者在翻译每一句台词前，必须先看发言人 `model` 或 `teller` 标识，自动切换心理模型：
  - **浮士德**：常见第三人称自称，保留原文第一人称例外，具体语气随剧情；
  - **良秀**：极短单句，烟火气与刀锋，招牌四字/多字全角点式缩写（如 `寸·铁·杀·人`）；
  - **默尔索**：军队内务条令式陈述，极度服从，绝不主动引申，只在收到指令时行动；
  - **堂吉诃德**：高亢骑士古风，自称“吾”，称但丁为“经理老爷”，充满感叹号与对正义的狂热；
  - **奥提斯**：职业军官口吻，唯经理马首是瞻，对其他罪人横加训斥，严禁口语懈怠；
  - **但丁**：全部语言由尖括号包裹 `<……>`，钟表机芯跳动声，承载全员痛楚的痛苦管理者。

#### (3) 核心伏笔的形式对等（Formal Equivalence）
- 当韩文或英文出现贯穿多部作品的核心概念词时，必须采取绝对一致的对等直译，不可随意换用同义词：
  - 例：`Clear All Cathy` ➔ 坚决翻译为 **《清除凯茜》**，绝不意译为“抹去凯瑟琳的记忆”；
  - 例：`Golden Bough` ➔ **金枝**；
  - 例：`Light` ➔ **光之种**；
  - 例：`The City` ➔ **都市**；`The Outskirts` ➔ **郊区**；`The Ruins` ➔ **遗迹**。

### 2.2 语域二：战斗技能与机制文本（Combat & Mechanics）

战斗技能（`Skills_*.json`）、被动（`Passives_*.json`）、关键词（`BattleKeywords-*.json`）与增减益（`Bufs-*.json`）是游戏的数值交互界面。其语言本质是**代码的自然语言表达**，必须遵循工业级精确。

#### (1) 逻辑触发公式化结构
零协会机制文本采用严格的标准化逻辑流转模式：
$$\text{[触发时机]} \implies \text{若 [前置条件]，则 [执行效果] (最多限制/特定说明)}$$
- **标准范例**：
  - `[OnSucceedAttack] 若目标的[流血] 强度不低于5，则使其受到5点暴食属性固定伤害(每回合最多2次)`
  - `[DefeatDuel] 下回合使自身获得1层[强壮] 与2层[呼吸法] `

#### (2) 动词三元组法则（Verb Triad Rule，L06门禁）
严格界定动作动词，杜绝“赋予”、“获得”、“施加”的随意混用：
1. **正面状态层数 / 次数**：一律用 **获得**。
   - 正例：`使自身获得3层[充能] `、`使全体友方单位获得1层[守护] `。
   - 反例：`对自身施加3层充能`（错误）、`赋予自身1层守护`（错误）。
2. **负面状态层数 / 次数**：一律用 **施加**。
   - 正例：`对目标施加2层[流血] `、`对所有敌方单位施加1层[易损] `。
   - 反例：`让目标获得2层流血`（严重违规）。
3. **数值 / 强度等级变化**：一律用 **增加** / **减少**。
   - 正例：`使目标的[破裂] 强度增加3点`、`使自身的防御等级减少2点`。
   - 反例：`对目标施加3点破裂强度`（错误）、`自身获得2点防御等级`（错误）。
4. **状态衰减 / 消耗**：一律用 **消耗** / **降低**。
   - 正例：`消耗10层[充能] `、`本回合结束时，使自身的[呼吸法] 次数降低1`。

#### (3) 本工作区战斗关键词约定

以下中文键与空格要求来自 AGENTS.md；零协会上游另允许方括号内部键，不能把本地限制当作上游全部语法。
- **后置空格（L04门禁）**：所有方括号词条后必须紧跟一个半角空格，例如 `[沉沦] 强度`、`[充能] 次数`。
- **严禁英文残留（Rule 8）**：绝不可出现 `[Vulnerable]`、`[Protection]`、`[ChargeNoir]`，必须查阅官方基准替换为规范中文（`[易损] `、`[守护] `、`[保存] `）。

### 2.3 语域三：E.G.O、异想体观察记录与怪谈（Abnormality & E.G.O Lore）

异想体（Abnormality）源自人类潜意识的心灵创伤，E.G.O 是将心灵具象化的武装。其文本包括脑叶公司/边狱公司观察日志、原典诗篇与侵蚀语音。

#### (1) 临床解剖与心理学病理档案风格
- **基调**：冷峻、克制、带有科研机构观察受试生物的解剖学质感。
- **用词特点**：偏好使用病理学、精神分析学与解剖学术语：
  - 使用“剥离”、“浸润”、“异化”、“精神解离”、“肉质增生”、“共振”、“坏死”。
  - 记录者语调带有《脑叶公司》主管日志与 SCP 基金会收容档案的冷静与隐秘恐惧。

#### (2) 意识流与狂乱神谕
- 当异想体或罪人处于 **E.G.O 侵蚀（Corrosion）** 或 **逆转神智** 状态时，文本转为断裂、重叠的意识流：
  - 允许使用破碎的长短句重叠与反复回响。
  - 保留宗教与神话母题的谶语感（如卡门的声音、原罪的诱惑、太阳的光晕）。

### 2.4 语域四：系统 UI 与探索交互（System UX & UI Strings）

系统 UI（`MainUIText-*.json`、`BattlePass-*.json`）与 RPG 探索互动（`RPGSystem/`）面向玩家的直观操作。

#### (1) 字符宽度控制与防溢出（Anti-Overflow）
- Unity TextMeshPro 文本框在移动端与 Steam 界面有着固定的空间约束。
- 中文字符平均宽度为英文的两倍，过长的中文译名会导致按钮文字挤压、换行错位甚至被截断（Clip）。
- **极简紧凑原则**：
  - 英文 `Confirm Selected Personnel` ➔ 中文 **确认出战人员**（简洁有力）。
  - 英文 `Insufficient Extraction Resources` ➔ 中文 **提取资源不足**。

#### (2) 探索事件的桌游/跑团质感
- RPG 迷宫探索文本借鉴了 TRPG（跑团）与克苏鲁神话调查员检定的语境：
  - 检定提示统一使用：`[暴食属性判定] 胜率极高`、`[理智值检定] 难度：难`。
  - 选项描述使用客观互动动词：`拨开缠绕的荆棘`、`试探性地敲击门扉`、`退回阴影之中`。

## 3. 常见汉化误区与纠偏自查清单 (Anti-Patterns & Traps)

| 序号 | 违规/失真现象 | 错误表现形式 | 零协会纠偏范例 | 归属门禁 |
| :---: | :--- | :--- | :--- | :---: |
| 1 | **全角波浪号乱码** | `获得10～15点护盾` | `获得10~15点护盾` | **L02 (FATAL)** |
| 2 | **关键词缺后置空格** | `对目标施加2层[流血]并造成伤害` | `对目标施加2层[流血] 并造成伤害` | **L04 (ERROR)** |
| 3 | **动词三元法则混淆** | `对目标施加5点破裂强度` | `使目标的[破裂] 强度增加5点` | **L06 (ERROR)** |
| 4 | **残留英文机制标识** | `获得2层[ChargeNoir]` | `获得2层[保存] ` | **Rule 8 (ERROR)** |
| 5 | **乱用网络烂梗破坏沉浸** | “这技能简直小黑子露出鸡脚了” | 严肃保持世界观原意，严禁梗化 | **文风红线** |
