# 都市零协会本地化研报：韩汉跨语际句法转译与语气映射法则 (Korean-to-Chinese Syntax & Speech Level Guide)

## 1. 跨语际翻译概论：韩语与汉语在游戏本地化中的结构张力

《边狱公司》（Limbus Company）的原文为韩语（Korean）。韩语属于典型的黏着语（Agglutinative Language），句法结构为 **SOV（主语-宾语-谓语）**；而汉语属于孤立语（Isolating Language），句法结构为 **SVO（主语-谓语-宾语）**。

在将月亮计划（Project Moon）的剧情对话与系统机制自韩译中时，单纯的“词对词映射”（Word-for-word translation）会导致严重的句法倒错、主谓脱节以及语气失真。以下句法说明为本地整理，未附上游出处的矩阵与示例不视为零协会官方规则。

## 2. 韩语敬语阶称与角色语气色彩映射矩阵 (Speech Levels to Character Voice)

韩语拥有高度发达的敬语阶称系统（Speech Levels），通过谓词词尾的变化精准表达说话者与听话者之间的社会阶层、辈分、亲疏度与权力关系。零协会在汉化时，根据韩语阶称建立了一套**零协会中文语气对照谱系**：

| 韩语阶称系统 | 语法词尾特征 | 语体庄重度与社交距离 | 边狱公司典型代表角色 | 中文转译标准与典型语气句式 |
| :--- | :--- | :--- | :--- | :--- |
| **하십시오체**<br>(极高尊称体 / 格式体) | `-습니다 / -습니까`<br>`-(으)십시오` | 最高庄重度、绝对服从、军纪秩序、官方公文 | **奥提斯** (对但丁)<br>**默尔索** (汇报时)<br>**卡戎** (报告路况) | - 必须使用“敬请”、“遵命”、“已完成确认”<br>- 句式工整短促，杜绝任何日常口语拖音<br>- 范例：“报告经理，前方阻碍已清扫完毕。” |
| **해요체**<br>(非格式体敬语 / 亲切体) | `-아요 / -어요`<br>`-(으)세요` | 礼貌、文雅、社交得体，有距离但温和 | **浮士德** (自称浮士德)<br>**以实玛利** (常态)<br>**格里高尔** (日常) | - 现代普通话礼貌语气，使用“请”、“……呢”、“……吧”<br>- 保持平稳客观的知识分子或常识人声线<br>- 范例：“浮士德认为，这项方案存在计算冗余。” |
| **하오체 / 하게체**<br>(拟古体 / 权势长辈体) | `-오 / -소`<br>`-(으)시게 / -네` | 古雅、戏剧感、旧式封建文人或长辈对下属 | **堂吉诃德** (骑士自命)<br>**李箱** (旧式文人自言) | - 堂吉诃德使用“吾”、“汝”、“……是也！”<br>- 李箱使用“此物”、“……罢”、“固然如此”<br>- 范例：“汝且退后，此乃吾之正义征途！” |
| **해라체 / 해체**<br>(卑称体 / 亲昵直截体) | `-다 / -냐`<br>`-아 / -어 / -지` | 极度平视、无社交掩饰、粗鲁野性、底层放肆 | **希斯克利夫**<br>**良秀**<br>**罗佳** (同伴互动) | - 句式直白甚至带粗砺感，省略繁复修饰<br>- 允许使用“喂”、“老子”、“啧”、“闭嘴”<br>- 范例：“啧，吵死了。再叫就把你的舌头割下来。” |

## 3. 韩汉句法拓扑重塑与长从句切分艺术 (Syntactic Restructuring)

### 3.1 SOV 倒装为 SVO 的逻辑流梳理
韩语中谓语动词始终放在句末，修饰语层层前置；中文则倾向于“主语 + 动作谓语 + 宾语/补语”。
- **韩文句法特征**：`[主语] + [各种嵌套的从句与修饰词] + [宾语] + [句尾核心动词]`
- **生硬直译弊端**：若顺着韩语顺序翻译，会导致中文句子前缀长达几十个字、头重脚轻，直到最后一个字读者才知道“干了什么”。
- **零协会重塑原则（前置主动切分）**：
  - 将句末核心动词提前；
  - 将韩语长状语拆解为“先交代背景/动作，再承接结果”的两个独立中文短句。
- **实战范例**：
  - **韩文原文**：단테가 황금가지를 회수하기 위해 버스에서 내려 위험한 골목으로 뛰어들어가는 것을 본 이스마엘은 한숨을 쉬었다.
  - **机械直译（恶性）**：看着为了回收金枝而从巴士下来跳进危险小巷里的但丁的以实玛利叹了一口气。
  - **零协会重构（优雅）**：见但丁为了回收金枝径直跃下大巴、冲入危机四伏的后巷，以实玛利无奈地叹了一口气。

### 3.2 常见韩语连接词缀的中文翻译定式

| 韩语从句连接词 | 原生语法功能 | 零协会推荐中文转译方式 | 翻译禁忌 |
| :--- | :--- | :--- | :--- |
| **`-면서`** | 伴随动作 / 同时发生 | “一边……一边……” / “随之……” / 逗号直接并列连动 | 严禁生硬套用“在……的同时”，造成官僚长句 |
| **`-는데`** | 背景铺垫 / 轻微转折 | “然而……” / “不过……” / 破折号推进叙事 | 严禁通篇用“但是”，韩语 `-는데` 很多时候仅是话题引申 |
| **`-기 때문에`** | 因果解释 | 前置“鉴于……”、“因……”，或后置“……正因如此” | 机制文本中统一使用“由于……”或“……时” |
| **`-ㄹ 때마다`** | 频率触发（机制核心） | **“每当……时，”** (如：每当暴击命中时) | 译文应准确传达频率条件；没有代码证据表明中文措辞负责触发战斗逻辑 |

## 4. 月亮计划专属专有名词构词法 (The City Terminology Matrix)

月亮计划创造了一个极具辨识度的异域反乌托邦社会结构。专有名词绝不可随意翻译，必须遵循既有世界观的构词谱系：

### 4.1 空间与地缘政治架构
- **The City (도시)** ➔ **都市**（而非“城市”）：指代月亮计划世界的全部文明聚集地，带有资本异化与冷酷铁律。
- **The Nest (둥지)** ➔ **巢**：由翼（大型企业）控制的安全区域，居民被称为巢民。
- **The Backstreets (뒷골목)** ➔ **后巷**：没有治安保障的庞大贫民窟与灰产聚集区。
- **The Outskirts (외곽)** ➔ **郊区**：都市高墙之外未受都市法保护的废土。
- **The Ruins (유적)** ➔ **遗迹**：埋藏古代特异点与异想体未知源头的地下深渊。

### 4.2 权力与商业实体
- **The Wings (날개)** ➔ **翼**：从 A 公司到 Z 公司掌管世界命脉的 26 家超级寡头企业。
- **Singularity (특이점)** ➔ **特异点**：翼所持有的超越物理常理的绝密超科技。
- **The Head (머리)** ➔ **首脑**：管理都市一切规则的最高统治阶层，涉及 A、B、C 公司的组织分工需回查原作，不把未定位的公司分配当成译名定义。
- **The Fingers (손가락)** ➔ **指 / 五指**：后巷各大黑道巨头，分为拇指（严苛军纪）、食指（传令崇拜）、中指（血亲复仇）、环指（艺术杀戮）、小指（神秘誓约）。
- **Fixer (해결사)** ➔ **收尾人**：受雇解决一切委托的都市合法武装从业者。
- **Association (협회)** ➔ **协会**：总管收尾人的 12 大专门职能公会（如 하나协会统筹评级，し协会专攻暗杀，Zwei协会专攻保护，六协会专攻集团作战，Seven协会搜集情报；现实中的都市零协会是汉化团队，不属于游戏内协会）。

## 5. 文化专有项、双关谐音与缩写的本土化解构方案 (Puns & CSIs)

### 5.1 李箱（Yi Sang）的同音双关
- **语源**：李箱的原型为近代文豪金海卿，在韩文中“李箱”（이상）与“以上”（이상，表示结束、至此）完全同音同字。
- **汉化方案**：在自我介绍与总结发言中，巧妙保留双关互文：
  - 原文：“이상입니다.”
  - 零协会译：“我是李箱。以上。”（既交代了姓名，又传达了报告完毕的冷峻文人做派）。

### 5.2 良秀（Ryōshū）的四字点式缩写
- **语源**：良秀说话喜欢取每个词的首字进行极致压缩（如 `예·아·모` 取自 `예술도 아주 모르는 것들`）。
- **汉化方案**：
  - 必须采用**符合中文成语/四字熟语节奏**的中文短语；
  - 汉字之间**必须使用全角中圆点 `·`**；
  - 必须在辛克莱或后文的吐槽中留出完美闭环的解释空间。
  - 例：`骨·断·自·明`（骨肉断裂之理不言自明）、`寸·铁·杀·人`（以寸芒之刃夺人性命）。

### 5.3 堂吉诃德（Don Quixote）的爱驹与古风
- **语源**：堂吉诃德称呼自己的特制运动鞋为塞万提斯名著中的瘦马 Rocinante（韩文：로시난테）。
- **汉化方案**：采用杨绛先生名译 **“驽骍难得”**，既契合音译，又传达出“驽钝之马却难能可贵”的荒诞骑士精神。
