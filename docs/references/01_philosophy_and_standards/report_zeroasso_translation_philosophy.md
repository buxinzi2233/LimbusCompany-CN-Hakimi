# 零协会翻译规范与本项目的语义忠实原则

## 1. 来源及适用范围

本篇以[零协会文档站](https://www.zeroasso.top/docs/main/)、[罪人语言风格](https://www.zeroasso.top/docs/translate/sinnerstyle/)及[观察记录风格](https://www.zeroasso.top/docs/translate/sinnerrep/)为可查依据，核验日期为2026-09-20。

公开规范能证明具体用语建议，不能证明旧稿所称的“近期哲学蜕变”“四大理论支柱”“40多位资深双语译者”或Discord争议词表决机制；这些说法未提供团队声明、名册或讨论记录，故不列为零协会事实。

## 2. 能直接指导翻译的规范

| 项目 | 上游依据 | 本项目的执行边界 |
| --- | --- | --- |
| 角色语言有区别 | 语言风格页分别说明各人的人称、敬语和语气 | 结合韩文及上下文，不能强行套入人设模板 |
| 原文例外要保留 | 浮士德条提及偶尔自称“我”；希斯条反对擅自加重脏话 | 不抹掉例外，不凭印象增强粗俗、古风或情绪 |
| 保持原有断句 | 卡戎条建议结合语音确定断句 | 不任意扩句；未听语音时不声称已核验演出 |
| 报告按角色处理 | 默尔索条说明短横杠习惯并列出不同收尾 | 区分正文与插入批注，结尾按原文对应 |

人物资料包含12位罪人及但丁、维吉利乌斯、卡戎共15位主要人物，不能将15位统称为罪人。

## 3. 文学与翻译理论的用途

语义忠实、术语承接、形式对等、归化与异化可作为分析译文的工具；本项目采用这些角度，不等于零协会公开宣称采用某一学派或理论体系。

保留《局外人》《白鲸》《呼啸山庄》等互文研究，但须先定位游戏韩文、已有中文及文学原作；不能把读者感受、100%阅读等效或未经量化的社区共识写成事实。

“清除凯茜”的形式效果可以研究，相关记忆变化应按剧情判断；希斯克利夫仍记得凯茜，不能概括为所有人无例外遗忘，见[希斯克利夫档案](../02_character_personas/sinners/07_heathcliff.md)。

## 4. 新文本的工作原则

先查零协会基准，再查我们已译的同名实体和相邻剧情，最后用同ID韩文核对语义与确定程度；新增译名须标明项目暂定状态。

原文有幽默、俚语或双关时应传达其功能；禁止译者额外塞入热梗，不将本地偏好冒称为零协会全面禁用幽默的政策。

未定位示例、心理推测及哲学类比不能覆盖原文；具体规范与验证流程以[翻译指南](../../TRANSLATION_GUIDE.md)为准。
