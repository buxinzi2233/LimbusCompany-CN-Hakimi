# 都市零协会汉化规范调研报告（二）：命名存档体系与术语库研报

## 1. 调研背景与命名存档（Name Archive）演进
在《边狱公司》（Limbus Company）的汉化迭代中，早期分散的术语表已正式升级重构为“**命名存档**”（Name Archive）。该体系承载着整个月亮计划世界观的专有名词体系，是保证所有汉化组员、审校与外部协同统一技术语言的“单一事实来源”（Single Source of Truth, SSOT）。

入口：[零协会命名归档迁移说明](https://www.zeroasso.top/docs/translate/namearchive/)。本研报旨在对齐零协会命名存档库，系统梳理人物/人格、E.G.O、异想体、组织阵营、战斗状态等核心术语与翻译映射逻辑，杜绝新赛季文本中出现“一词多译”或“设定偏差”。

### 2.2 都市势力与组织阵营命名规范
以下是不同性质的组织类别，不是同一行政树的上下级：
1. **翼（Megacorporation）**：
   - `L公司`（Lobotomy Corporation）：脑叶公司。
   - `K公司`：公司字母名不是“摘除”的词源；`Personalities.json` ID `10605.title` 是“K公司 3级摘除人员”，[零协会专页](https://www.zeroasso.top/archive/name/k-corp-class-3-excision-staff/)解释的是人员职称，不是公司名称。
   - `T公司`：时间征收（Time），科技为“时间延缓/保存”。
   - `W公司`：跃迁（Warp），下属部队为“**W公司清扫人员**（基准 `Personalities.json` ID `10202/10302/10503`）”。
2. **协会（Associations）**：
   - 名称涉及不同语言的数字，不能凭数字译法自行补全尚未定位的组织名：
     - 可定位例证为 `Personalities.json` ID `10708` 的 Öufi协会、ID `10910/11011` 的 Девять协会；Eight协会名称可见灰机协会导航但职能待定位，十二协会名称在本轮证据范围内待考证，不设猜测别名。其余名称按对应资源逐项查证。
   - 中文统一格式：`X协会`，如 `六协会南部分科4科`。
3. **手指（The Fingers）**：
   - `拇指`（Thumb）：严酷阶级与枪械礼仪。
   - `食指`（Index）：指令（Prescript）执行。
   - `中指`（Middle）：义气、复仇账本与纹身。
   - `环指`（Ring）：艺术暴力美学。
   - `小指`（Pinky）：笔记记载重视“仁”、隐藏身份，见 `DanteNoteDetail_150`；未确认暗杀专职。
4. **特色收尾人（Color Fixers）**：
   - `붉은시선` -> **猩红视线**（Vergilius，零协会定名，严禁错译为“红色视线”）
   - `검은침묵` -> **漆黑噤默**（Black Silence，前作继承官方定名，严禁臆造为“漆黑苦难”）
   - `보랏빛눈물` -> **堇紫泪滴**（Purple Tear，[灰机维吉里乌斯](https://limbuscompany.huijiwiki.com/wiki/维吉里乌斯)使用此称号；不将旧稿自列别名当作零协会标准）

## 3. 命名存档的协同与扩展流程
1. **查重第一原则**：新赛季遇到新人物、异想体或技能名，必须先在 [命名存档](https://www.zeroasso.top/archive/main/)与本术语库中检索，确认无重名或同系列前例。
2. **音译与意译界限**：
   - 西方人物／神话背景先查零协会既有译名与对应原典；辞典音译可作参考，不覆盖已有定名；
   - 东方意象（如九人会、剑契、黑云会）严格依据汉字源流（Hanja）溯源还原。
