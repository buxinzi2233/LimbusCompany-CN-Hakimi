# 角色语料核验与统计使用边界

## 1. 来源与适用范围

本文只把能按文件、ID 和语言定位的内容作为原句证据，不把改写示例视为实机台词。
中文来源为 `references/baseline-zh-CN/`，韩文对照为 `references/baseline-KR/`；新章应另查当前游戏韩文资源。

旧的 `tools/corpus_stats.json` 保存了 15 位核心角色共 31932 条记录，但不是已认证的官方语料统计：`tools/corpus_analyzer.py` 读取工作区，人物按子串匹配，语音优先取 `desc` 而非 `dlg`，会误收标签或误判说话人。
统计中的代词数表示含该字符串的剧情行数，不能区分自称与他称，也不是包含人格语音的词频；在脚本和来源修正前，不得据此推导强制人物规则。

## 3. 可定位的中韩语料

### 3.1 东朗谈冬柏的状态

来源：`StoryData/S454B.json`，ID `24`，`model: 동랑`，说话人东朗。

- 韩文：`아니… 너도 알았잖아, 이상. 그 상태의 동백은 죽음을 바로 맞이할… 그것도 고통스럽게 흐드러져 버릴 상태였다는 걸.`
- 中文：`不……你也知道吧，李箱。那个状态下的冬柏即将迎接死亡……而且是以被痛苦淹没的状态。`

这条不能用来论证李箱的飞翔意象或说话风格。

### 3.2 浮士德的第一人称与胜利语音

来源：`PersonalityVoiceDlg/Voice_Faust_LCB_10201.json`。

| ID | 韩文 `dlg` | 中文 `dlg` |
| --- | --- | --- |
| `smalltalk_10201_3` | 단테, 모든 답을 알고 있다는 뜻이 제가 모든 질문에 대답해줄 수 있다는 뜻은 아니에요. | 但丁，我无所不知并不代表我有回答你每一个问题的义务。 |
| `battle_clear_10201_1` | 이런 일에 기뻐해야 할 이유가 있을까요? | 有什么值得为此高兴的理由吗？ |

`제가` 是第一人称；翻译应随原文，不能机械改成“浮士德”。零协会[罪人语言风格](https://www.zeroasso.top/docs/translate/sinnerstyle/)也保留第一人称例外。

### 3.3 引文采纳条件

资源文件不存在、ID 不存在或正文不相符的片段，不作为实机引文保留；例如所查 `S648B.json` 只有 ID `0–23`，不能引用 ID `41`。
堂吉诃德的不同剧情阶段及各镜像人格需要分别定位原文，不能用未经定位的示例推导全时期、全人格适用的规则。

## 4. 后续提取要求

每条语料记录来源版本、文件、ID、说话人及原句；人物别名必须明确映射，不能把 `뫼르소엄마` 归入默尔索本人。
语音取 `dlg`，事件说明 `desc` 单独存放；统计应说明语言、字段、计数单位和是否覆盖人格语音。
官方中文、工作区自主翻译及写作示例必须分开，不能把工作区多数用法当成零协会规范。
