## 1. 文学渊源与人物内核

### 1.1 原型文学背景与哲学母题
浮士德的原型源自德国伟大文学家约翰·沃尔夫冈·冯·歌德的史诗级诗剧《浮士德》（Faust）。原著中的浮士德博士通晓神学、法学、医学与哲学，却深感人类知识的狭隘与生命的虚无，最终与魔鬼靡非斯特（Mephistopheles）签下灵魂契约：“若是我对某一瞬间说：停一停吧，你真美丽！那时你就把我铐起，我也甘愿走向沉沦。”

### 1.2 《边狱公司》世界观中的角色重塑与创伤
- **身份与地位**：[灰机浮士德](https://limbuscompany.huijiwiki.com/wiki/浮士德)的角色介绍明确其开发巴士引擎；“整个公司技术体系的真正缔造者”“脑罐引擎”“与LCA直接单线联系”超出该证据，不列为既定身份。
- **“浮全知网络”（The Faust Network）**：
  保留与其他浮士德的信息联系这一研究方向；连接范围、技术原理、能否随时取用均须逐条定位剧情。旧稿“所有世界”“时刻”“全知”不能作为统一前提，更不能由网络推成当前浮士德不是独立个体。
- **代价与冷漠**：“知识共享造成情感剥离”“知道所有结局却被契约禁言”是旧稿未附证据的心理及因果推论，不用于要求译文冷漠或全知。

## 3. 语言风格与句法指纹 (Linguistic Fingerprints)

### 3.1 常见第三人称自称与原文中的例外
浮士德最显著、最具辨识度的语言特征，是**在绝大多数正式对话中均使用“浮士德”作为主语自称**，极少使用第一人称代词“我”：
- **正例**：“浮士德认为，日光浴是一项有益活动。”
- **正例**：“浮士德知晓这背后的因果。”
- **使用边界**：不得脱离韩文人称判错；`Voice_Faust_LCB_10201.json` 的 `smalltalk_10201_3` 使用 `제가`，中文对应“我”。上述未附 ID 的句子只作表达示例，不是实机引文。

### 3.2 科学逻辑、绝对精准、零情感冗余
- **学术与统计学术语前置**：
  - 惯用语：“理所当然的结果。”、“误差仍在容许范围之内。”、“这并非最有效率的选择。”
  - 面对胜败时展现出神性淡漠：“不要因成功骄傲自满，不要对失败耿耿于怀。”
- **断句工整，严禁口语拖泥带水**：
  浮士德的句子逻辑关系严密（多用“鉴于……”、“基于以上数据……”、“因此……”），极少使用感叹号，更绝不使用语气词（如“啊啦”、“呢”、“嘛”）。

## 5. 本地化汉化红线与自查规范

1. **原文人称对齐**：
   在任何剧情对话与角色互动中，只要韩文原文使用了第三人称“파우스트는”，中文必须百分之百使用 **“浮士德……”**，绝不可顺手改写成“我”。
2. **红线二：杜绝娇嗲与傲娇语气**：
   浮士德是高维学者，不是动漫傲娇大小姐！严禁将她的自信翻译为“哼，我可是天才”之类的轻浮语气。
3. **红线三：维护技术词汇的高端质感**：
   涉及梅菲斯特巴士、脑罐、镜牢、金枝的对话，用词必须保持工程学与形而上学的高冷感。
