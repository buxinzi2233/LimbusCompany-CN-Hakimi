> **证据使用边界**：本篇保留文学研究与口吻分析；未附资源ID的关系矩阵、心理因果、例句和动作尚未逐条确认，不能作为游戏既定事实或强制台词模板，带文件名的引文也须按同ID核对；详见[统一来源规则](../../../TRANSLATION_GUIDE.md)。


## 1. 文学渊源与人物内核

### 1.1 原型文学背景与哲学母题
但丁的原型取自中世纪晚期意大利最伟大的诗人但丁·阿利吉耶里（Dante Alighieri）的史诗级传世名作《神曲》（Divina Commedia）。在《神曲》开篇，但丁在人生的中途步入幽暗的森林，在古罗马大诗人维吉尔（Vergil）的指引下，遍历地狱九圈（Inferno）、炼狱七层（Purgatorio）与天堂九重天（Paradiso），亲历世间罪孽的终极受罚与灵魂救赎。

### 1.2 《边狱公司》世界观中的角色重塑与创伤
- **失忆的“时钟头”与背负罪孽的管理者**：
  序章登场的但丁已是时钟头、失忆并遭追杀；换头过程、完整原因和失忆前身份不能凭登场状态补写。相关猜测保留为谜题，不将“特异点身份”列为已确认属性。
- **“回拨时钟”的沉重代价与受难者**：
  但丁拥有通过回拨发条将 12 位罪人从死亡中复活的逆天权能。然而，这项奇迹并非无代价的机械操作：**每一次复活，但丁都必须承受复活罪人带来的痛苦，不增添未经量化的“百分之百”或将每次痛苦细节固定化**。
- **从恐慌傀儡到真正领导者**：
  从第 0 章遭遇追杀与危险，到历经李箱、辛克莱、以实玛利、希斯克利夫等人的地狱篇章，但丁逐渐成长为全车罪人不可或缺的灵魂支柱与真正的领路人。

## 3. 语言风格与句法指纹 (Linguistic Fingerprints)

### 3.1 发声对白与内心旁白分别处理
但丁的发声对白常以半角 `<...>` 包裹，内心旁白不据此补括号；例如 [4D305A.json](../../../../references/baseline-zh-CN/StoryData/4D305A.json) `61–63、69` 为未加尖括号的第一人称思绪，`65` 才是带括号的发问，同 ID 韩文亦如此。

同场 `66` 由浮士德转达问题，`67–68` 中维吉里乌斯称自己没有听到，并解释只是根据表情作答。这支持区分听懂对白、转述与察言观色，不能推出“大巴神经直连”“脑电波转码”或“高阶存在都能听懂”。本次未核定能直接理解但丁的完整名单。

### 3.2 共情与成长的口吻边界
关心同伴、承受复原痛苦可作为风格线索，不能改写成永不生气、每次都先安慰他人的固定程序。`4D305A/13` 的粗口和 `S833I6/57–58` 的陪伴及自救边界均应保留，见下方逐条引文。

## 5. 本地化汉化自查

1. 保留原文对白的半角尖括号，并检查闭合；这是文本一致性要求，没有实机日志时不宣称缺一侧必然导致游戏闪退。
2. 按具体场景保留迟疑、愤怒、关心与担当，不用“慈悲经理”模板覆盖粗口或反问。
3. 时钟拟声按同 ID 原文和既有译文处理，不为每句话自动增添“嘀嗒”；上游[但丁语言风格](https://www.zeroasso.top/docs/translate/sinnerstyle/)强调平淡、合乎时宜及偶尔吐槽。
