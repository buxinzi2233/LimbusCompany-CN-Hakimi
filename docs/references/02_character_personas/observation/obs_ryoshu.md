# 良秀语言观察：缩写及演出证据边界

## 1. 可确认的语言规范

[零协会语言风格页](https://www.zeroasso.top/docs/translate/sinnerstyle/)将良秀的称呼概括为少叫名字、未见尊称，并给出 `除·缩·没·想`，展开为“除了缩写外没有想法”；旧稿扩成质问句改变了意思。

间隔号 `·` 是U+00B7，不应称为“全角点”；新台词出现缩写时，先查韩文及后续解说，再参考已有中文形式，不能为了四字整齐另造解释。

旧稿 `寸·铁·杀·人`、`画·龙·点·睛`、`老·实·呆·着` 及其血腥解释未附台词ID，不列为经典映射；也不强制每句少于十字或对但丁一律称“钟表头”。

## 2. 演出与身世材料的限制

抽烟、使用带鞘武器可以作为观察方向；“每逢战前必定点烟”“露出数毫米锋刃”“永远只看颈动脉”等结论没有演出定位，不作为翻译依据，也不向对白补写动作。

《地狱变》属于文学参考，不能直接推导游戏角色背负原著画师的同一命运；第九章已有披露应优先于旧前瞻，详见[良秀人物资料](../sinners/04_ryoshu.md)及已译 [StoryTheaterDanteNoteDetail_11.json](../../../../workspace/LLC_zh-CN/StoryTheaterDanteNoteDetail_11.json) 的 `DanteNoteDetail_156`、`DanteNoteDetail_163` 对父辈、阿赖耶识的记录，后者还区分其与概念焚化炉的原理性质。

## 3. 对话审校方式

辛克莱理解缩写的互动需要按具体场景核对，不能把“全职翻译官”“每次准确解包”当作机制；原文没有缩写、烟雾或艺术隐喻时，不额外添加。
