# 奥提斯观察记录：来源与格式

来源：零协会[罪人观察记录规范](https://www.zeroasso.top/docs/translate/sinnerrep/)的奥提斯部分。

## 格式与语气

按原文保留事后报告的开头、遭遇时间及结束语；上游明确将时间写法作为可变例子，不能自行增加战损数字或战术细节。
上游给出的结尾是结束报告并致谢，不要求额外的效忠宣誓；原文没有“呈报管理者大人”时，不强行套入该短语。
对但丁与同僚的具体称谓依原文和语境处理，不把所有同僚统称为“乌合之众”。

## 可定位的日志

[AbnormalityGuides.json](../../../../references/baseline-zh-CN/AbnormalityGuides.json) `8038/storyList`（凤老爹）与同 ID 韩文：等级0报告17点20分左右的初遇，正文以感谢收尾；等级1报告03点10分左右的交战，再以结束报告和感谢收尾。两个时间分别属于两次记述，不合并成统一模板，也不误称该条对象为普通异想体——记录内判断其属于扭曲。

等级1末尾对轻蔑称呼执行经理的反驳和等级0的同僚批注都应保留，不能把箭头之后的所有话都算作奥提斯本人的报告正文。

## 引文边界

未定位到资源 ID 的“减轻30%战损”片段不作为实机引文保留；不能凭军事风格推导实际战斗数值。
