# 罗佳言行观察：收税人事件、称呼与解释边界

## 1. 身份、喜好与来源层级

[IntroduceCharacter.json](../../../../references/baseline-zh-CN/IntroduceCharacter.json) `로쟈` 的中文名为罗佳，描述喜爱钱财、赌博和打赌，并提到以玩笑或眨眼回应指令、偶有情绪低落；同 ID 韩文可核对。这是公司视角的简介，不足以推导糖分成瘾或赌博必定出于创伤防御。`LCCB-OBS-09` 是旧稿本地编号。

游戏中可见“罗季昂”的称呼，但 `Rodion Romanovich Raskolnikov` 不应直接列为游戏角色完整姓名；[《罪与罚》英译](https://www.gutenberg.org/files/2554/2554-h/2554-h.htm)中的拉斯柯尔尼科夫与放贷者属于文学对照。

## 2. 第二章：行为事实与各方解释

[2D306B.json](../../../../references/baseline-zh-CN/StoryData/2D306B.json) 已核对当前中文基准、工作区与韩文：

- `65–66`：罗佳承认劈开老太婆的头。
- `71–72`：索尼亚说该人是25区收税人，其弟是中指成员。
- `73`：罗佳说自己为饥饿的邻居挥斧。
- `74–75`：索尼亚对此提出另一种动机解释，不能省略发言人后写成全知心理诊断；`75` 韩文的否定结构 `불과하지 않다는` 与中文的“不过是个平凡之人”存在字面差异，是否原文笔误须另查语音或修订记录，本轮不擅自改定。
- `76–78`：索尼亚说明中指报复，并讲述后巷居民的死亡；不据此补出“全街区人口无一幸存”的统计结论。

“非凡之人”、救世冲动、享乐作为保护色可以保留为文学或心理解读议题，但不得取代上述角色自述及争执。

## 3. 称呼、口吻与演出待核

零协会[昵称与观察记录规范](https://www.zeroasso.top/docs/translate/sinnerrep/)列有罗佳对格里高尔的“格雷格”、对以实玛利的“以实”等昵称，并不支持“对同伴一律直呼全名”。[语言风格](https://www.zeroasso.top/docs/translate/sinnerstyle/)建议随和、较少敬语以及半角波浪号；不是必须加“大姐我”“亲爱的”或固定地域方言的要求，`단테~` 本身不包含“亲爱的”一词。

反复搂肩拍背、紧张时加快咀嚼以压制焦虑、翻转生锈筹码、指节发白、身高近一米八与单手挥斧、特定独白必定瞬间变脸等细节尚未取得对应证据，保留为待核观察项目；当前文本不将这些写成既定生理数据或逐帧动作。
