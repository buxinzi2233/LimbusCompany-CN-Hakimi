# 罪人观察记录与昵称：来源及使用边界

观察记录以当前韩文及同 ID 的中文基准为事实依据；风格参照零协会[罪人观察记录规范](https://www.zeroasso.top/docs/translate/sinnerrep/)与[罪人语言风格](https://www.zeroasso.top/docs/translate/sinnerstyle/)。

## 昵称

按上游页面“罪人昵称”部分逐人查询，不自行补全不存在的昵称矩阵；未定位的称呼不标记为官方定名，也不凭角色外貌创造固定外号。
名称用“鸿璐”；人物文件排序、人格资源编号与罪人编号不是同一个概念，不能用列表第十位推断辛克莱为 10 号罪人（`StoryData/S951B.json` ID 114 明确为 11 号）。

## 记录格式

上游页面分别列出李箱、浮士德、默尔索、奥提斯的记录格式及例外；它是针对用语习惯的整理，不证明这四人撰写了绝大多数观察记录。
这些JSON没有单独的作者字段；使用上游格式匹配日志时，也须核对正文及批注，不能只凭句尾自动认定发言人。
按当前条目的开头、结尾和段落结构翻译，不额外插入效忠宣誓、战损百分比、文学修辞或固定模板。
未附资源 ID 的本地范例不是实机台词；未提供影像和时间码的微表情描述不是已核实演出事实。

## 本地审查记录

按[翻译资料入口](../../../TRANSLATION_GUIDE.md)查上游规范和已有译文，只在具体称呼、语气或句义存在冲突时继续核对；当前问题见[审查状态](../../../reports/knowledge-base-audit.md)。公司简介的叙述视角、当前韩文与中文基准的差异均应保留，例如希斯克利夫简介的否定句不能仅凭中文基准反推其思考能力；具体见[希斯克利夫观察记录](obs_heathcliff.md)。
