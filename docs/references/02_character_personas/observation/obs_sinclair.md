# 11号罪人辛克莱：语言观察与剧情核验

## 1. 第三章事实与文学原型

辛克莱会反抗克罗默，但第三章最终击杀克罗默的是德米安，不能写成辛克莱“手刃克罗默”；见[灰机Wiki德米安条目](https://limbuscompany.huijiwiki.com/wiki/德米安)及本地 [3D309A.json](../../../../references/baseline-zh-CN/StoryData/3D309A.json) `5–6`，德米安自述让克罗默消失；同 ID 韩文为 `그래서 저 크로머를 사라지게 했어.`，具体打击动作仍应看演出。

黑塞[《德米安》德文原作](https://www.gutenberg.org/files/41907/41907-h/41907-h.htm)第一章“Zwei Welten”、第二章“Kain”中的谎言、两个世界和该隐印记可以用于文学对照，不能将原著事件逐项套成游戏履历；详见[辛克莱人物资料](../sinners/10_sinclair.md)。

## 2. 语言方向

[零协会语言风格页](https://www.zeroasso.top/docs/translate/sinnerstyle/)强调辛克莱常用敬语、对话有晚辈感，并提醒N公司人格仍对但丁使用敬语；不能将紧张写成无能，也不能在战斗时一律改成无敬语的狂吼。

结巴、疑问及对但丁的称呼应逐句核对韩文；“我、我……”不是每句都必须添加的开头，“但丁先生”也不能无视原文变化成为唯一模板。

旧稿“骨肉断裂之理不言自明”等互动句没有台词ID，不作为实机引文；原文没有文学暗示时，不主动加上破壳或阿布拉克萨斯意象。

## 3. 演出与新剧情

“每次抓头发后准确解包”“听到金属声必然干呕”等未有演出定位，不列为固定动作；PTSD等医学标签不能替代剧情证据，镜像人格表现也不能直接等同本体。

已译第十章中的克罗默姐姐自述及模型名应保持与韩文对应，不因旧印象自行重写身份；其证据边界见[第十章考据](../../03_season8_literary_research/03_canto10_lore_and_audit.md)。
