## 2. 称谓与现有语音

零协会[语言风格](https://www.zeroasso.top/docs/translate/sinnerstyle/)归纳了骑士语气中的“吾”“汝”及对但丁、向导的“老爷”称呼，且指出称呼对象不同会有变化；不能强制所有场景只有“经理老爷”一种叫法，也不固定感叹号数量。

[Voice_Donquixote_LCB_10301.json](../../../../references/baseline-zh-CN/PersonalityVoiceDlg/Voice_Donquixote_LCB_10301.json) 与同 ID 韩文、[基础E.G.O语音](../../../../references/baseline-zh-CN/EGOVoiceDig/Voice_EGO_DonQuixote_3.json) `battle_awaken_20301_1/2` 提供已有译法；使用[人物档案第4节](../sinners/03_don_quixote.md)中的可定位条目，不把“踏平眼前一切邪祟”等改写称为实机台词。

## 3. 演出待核与使用限制

逐步跺脚、双拳位置、披风扬起、摸徽章的固定顺序、他人触摸周边后的惊叫、脱鞋后抬下巴俯视等细节，旧稿没有给出场景、影像或时间码，本轮也未证实，保留为待观察项目。收藏周边的简介不能证明这些逐帧动作，更不能据此为翻译补写动作与动机。
