# 格里高尔言行观察：异化、战争记忆与具体语境

## 1. 游戏身份与文学参考

[IntroduceCharacter.json](../../../../references/baseline-zh-CN/IntroduceCharacter.json) `그레고르` 与韩文描述其相对好相处、偶有冷嘲，并说情绪或环境急变时，身体部分乃至全身可能出现虫化；物种文字含遮蔽部分，不能由此确定全部生物学性质或写成“永远只有右臂不可逆变化”。

[《变形记》英译](https://www.gutenberg.org/files/5200/5200-h/5200-h.htm)开篇的Gregor Samsa属于小说人物；游戏简介名为格里高尔，不据文学原型补全游戏姓氏。旧稿 `LCCB-OBS-12` 为本地文档排序，游戏罪人编号为13，见[ScenarioModelCodes](../../../../references/baseline-zh-CN/ScenarioModelCodes-AutoCreated.json) `그레고르`。

## 3. 口吻与未核演出

零协会[语言风格](https://www.zeroasso.top/docs/translate/sinnerstyle/)建议随和而保有一定尊重，对但丁可见“老兄”“经理兄”。不能把 `관리자 양반` 固定替换为“老板”，也不凭年龄给辛克莱新增“老弟”等称呼；现有语音见[人物档案第4节](../sinners/12_gregor.md)。

旧烟盒的材质及磨损、必定点火的时机、用左手按住虫臂且说“安分点，伙计”、每次第一个劝架、闻到苹果后瞳孔收缩与虫臂升温等细节，均缺对应台词或影像证据，保留为待核观察项目。创伤与异化的文学研究仍有价值，但翻译不得据此添加温度、固定动作或心理诊断。
