# 希斯克利夫言行观察：原文否定句、记忆与口吻

## 1. 来源及中文基准差异

[IntroduceCharacter.json](../../../../references/baseline-zh-CN/IntroduceCharacter.json) `히스클리프.description` 描述他行动优先、思想感情外露，也包含公司视角的挖苦；不应把这种叙述当作心理诊断。旧稿 `LCCB-OBS-07` 只是本地编号。

该条韩文有 `수감자의 사고 체계에 심각한 문제가 있는 것은 아님을 숙지해 주시길 바랍니다.`，否定的是“思考体系存在严重问题”；当前中文基准和工作区却写“希望您谨记在该罪人的思维模式中并不存在深入思考这一项”，两者并非同义。此差异单独登记，不能用中文基准证明他没有思考能力，也不能抹去原文后续确有的挖苦；本次未修改该游戏JSON。

零协会[语言风格](https://www.zeroasso.top/docs/translate/sinnerstyle/)也明确反对特意降低他的文化水平或加重脏话。俚语、讽刺、礼貌与情绪变化均应按具体原文，撤出“绝不文雅”“杜绝任何礼貌用词”等人设禁令。

## 2. 第六章后的记忆

[已有译文E901B](../../../../workspace/LLC_zh-CN/StoryData/E901B.json) `18–19、23、27` 与同 ID 韩文：但丁说出凯瑟琳的名字，希斯说至少但丁还记得，旁白说明两人仍会互相核对记忆。参见[灰机9.5-01战前](https://limbuscompany.huijiwiki.com/wiki/9.5-01战前)。

因此后续涉及凯瑟琳时，不应一律翻成“忘记重要之人却想不起来”。他对他人忘却的反应、对凯瑟琳的记忆、对具体往事是否清楚，是不同问题；不设“雨夜、闪电、挚爱”三个词必然触发按胸和怒吼的动作规则。

## 3. 文学对照与待核演出

[《呼啸山庄》英文原作](https://www.gutenberg.org/files/768/768-h/768-h.htm)第1章由洛克伍德描写他的外貌与举止，第4章叙述恩肖从利物浦街头带回孩子；书中人物使用的“gipsy”标签不能直接成为游戏角色已确认的族裔。阶级、收养、爱与复仇可作为文学研究主题，不能将小说人物的一生与死亡结局当成游戏履历。

右肩扛棒、连续敲地、遇到贵族词句就抓乱头发、听到特定词后数秒惊恐、攻击性由某种心理防御直接引发等旧稿断言，仍缺逐场景影像或剧情证据。它们保留为待核观察题，不作为动作模板、精神疾病诊断或固定昵称表；已有语音引文见[人物档案第4节](../sinners/07_heathcliff.md)。
