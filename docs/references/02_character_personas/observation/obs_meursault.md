# 默尔索观察记录：条目、收尾与证据边界

## 1. 已核验的格式

[零协会观察记录规范](https://www.zeroasso.top/docs/translate/sinnerrep/)说明默尔索报告采用短横杠，并在中文短横杠后补半角空格；这适用于报告正文，不应吞并其他罪人以箭头开头的批注。

本地交叉依据为 [AbnormalityGuides.json](../../../../references/baseline-zh-CN/AbnormalityGuides.json) 与游戏 `kr/KR_AbnormalityGuides.json`，条目 `8015`（你想挨打吗？很想？）的 `storyList`：

| 观察等级 | 韩文末条 | 已有中文末条 |
| --- | --- | --- |
| 0、1 | `-추가적인 관찰이 이뤄지면 새롭게 서술하겠다.` | `- 如果有任何新的发现，我会在未来的报告中提及。` |
| 2 | `-더 알 수 있는 사실은 없는 것 같으니, 관찰 일지는 이것으로 마치겠다.` | `- 没有更多的额外发现。观察日志结束。` |

等级0及2还有箭头批注，不能统一替换成短横杠；原稿“表皮对斩击脆弱／突刺产生反震／立即部位破坏”的所谓实机中韩例句未在本机韩文资源定位，已撤出引文。

## 2. 语气与原文优先

简洁、条理清楚是风格方向，不能推导出绝对没有感受或判断；`8015/level 2` 的韩文含 `느낌`、`같기도 했다`、`같았다` 等感觉与推测表达，中文也保留触感描述。

旧稿规定的唯一结尾“结论如上／以上便是全部”与上述中韩条目和上游范例不符；新报告应按其自身结尾翻译，不能添加原文没有的收尾句。

## 3. 第十章材料的关联

文学原型不等于默尔索没有情感；已译 `StoryData/S1061B.json` 及RPG第4层 `D40816/0–5` 应作为新剧情参考，不能以早期印象抹掉母亲与恐惧相关话语，详见[默尔索人物资料](../sinners/05_meursault.md)。
