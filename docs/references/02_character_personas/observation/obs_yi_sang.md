# 李箱观察记录：来源与格式

来源：零协会[罪人观察记录规范](https://www.zeroasso.top/docs/translate/sinnerrep/)与[罪人语言风格](https://www.zeroasso.top/docs/translate/sinnerstyle/)的李箱部分。

## 句式与结尾

上游分别列出固定结尾和类似结尾的例子；按韩文实际句式选择对应中文，不将所有署名记录的结尾强制替换为同一句。
保留较文雅的白话风格，不任意添加古诗、文言或隐喻；描述伤害类型和抗性时，应先保证原文机制信息不变。

## 可定位的观察日志

[AbnormalityGuides.json](../../../../references/baseline-zh-CN/AbnormalityGuides.json) `8002/storyList`（终末日历）与 `KR_AbnormalityGuides.json` 同 ID：等级0、1在箭头批注之前以 `보고는 이상이오.` 收尾，中文为“以上，结束报告”；等级2出现中断、修正带抹去的记述与他人批注，没有相同收尾。批注直接提到李箱，且上下文明确正在讨论他的观察记录。这一例子不能推广成所有等级固定模板。

## 引文边界

本地未附文件及 ID 的“甲壳坚固、突刺薄弱”片段不作为实机引文保留，也不用于证明某个异想体的机制。
新例句须同时记录资源文件、ID 和原文；名字双关可以解释用词，但不能代替剧情出处。
