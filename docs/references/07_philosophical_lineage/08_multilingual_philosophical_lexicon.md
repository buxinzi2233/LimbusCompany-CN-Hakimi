## 模块三：现象学还原与此在本体论（胡塞尔·海德格尔·雅斯贝尔斯）

## 六、 跨语际汉化防雷速查总表

1. **韩文 `실존` (實存)**：
   - 确认涉及相应哲学概念时，可译为**“存在”**或**“实存”**。如 *실존주의* -> **存在主义**。
2. **韩文 `부조리` (不條理)**：
   - 对应法语 *L'Absurde*，标准中文译名为**“荒诞”**或**“荒谬”**。避免直译成生硬晦涩的汉字词“不条理”。
3. **韩文 `권력의지` (權力意志)**：
   - 对应德语 *Wille zur Macht*，标准译名为**“权力意志”**或**“强力意志”**。
4. **韩文 `자기기만` (自己欺瞞)**：
   - 对应法语 *Mauvaise foi*，标准译名为**“自欺”**。
5. **韩文 `앙가주망` (借音法文 Engagement)**：
   - 哲学概念可参考**“介入／投身”**；普通参与、承诺等语境另按原文判断，不采用无条件替换。
6. **韩文 `피투성` (被投性) 与 `기투` (企投)**：
   - 对应德语 *Geworfenheit* 与 *Entwurf*；后者的中文译名与概念关系见 P38 的待核验标记，不作为已确定的多语同义词表。
