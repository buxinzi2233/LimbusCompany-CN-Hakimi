# 角色语言风格独立调研报告：12 号罪人 · 格里高尔（Gregor）

## 1. 文学渊源与人物内核
格里高尔取材自奥地利现代主义文学奠基人弗朗茨·卡夫卡（Franz Kafka）的中篇代表作《变形记》（Die Verwandlung）的主角格里高尔·萨姆沙。在《边狱公司》中，他曾作为旧 G 公司的生化实验受害者参与烟霾战争，右臂被异化改造为巨大的昆虫节肢。他既是被国家与家庭机器压榨抛弃的残疾老兵，又是历经世事沉浮、烟火气十足的疲惫中年人。他言谈随和、善解人意，习惯用自嘲与廉价卷烟消解残酷现实。

## 3. 句式结构与修辞特征

### 3.1 成年老兵的随和与生活烟火气
- **句末语调**：偏好使用“……吧”、“……呢”、“……啊”，语速平稳，带有吐出烟圈般的悠闲与无奈。
- **自嘲艺术**：不主动争抢风头，习惯在大家争吵时打圆场，充当车厢老好人。
- **标点规范**：多用六点省略号 `……` 与逗号，极少使用激进感叹号。

### 3.2 战场与烟草隐喻
- 经常提及点烟、烟灰、老骨头、泥潭、军粮等平民士兵日常，反对奥提斯式的军国主义狂热。

## 4. 台词经典范例与翻译对照

### 正确范例
- **韩文原文**：어이, 관리자 양반. 담배 한 대 피우고 시작하자고.
- **标准译文**：喂，经理兄。先抽根烟再开工吧。
- **神髓解析**：“经理兄”精准对应了韩语中带有人情味的 `양반` 与 `형`，既不冒犯，又透出成年老兵的江湖老练。

### 违规反面教材
- **错误译文 1（过度卑微）**：尊敬的但丁长官，请问是否可以允许我吸烟？（严重违背人设，变成奥提斯）
- **错误译文 2（街头混混）**：老表，来根华子！（过度网络梗本土化，破坏严肃的末日都市战争反思）

## 5. 汉化落地红线
1. **经理兄称谓锁定**：对但丁最标志性的亲切称谓为“**经理兄**”或“**老兄**”。
2. **严禁油腻烂梗**：保持卡夫卡式的深层荒诞与老兵悲凉，切忌翻译成低俗网梗。
3. **肢体厌恶感保留**：提及右臂虫肢时，必须保持其本能的厌烦与排斥情绪。
