# 角色语言风格独立调研报告：05 号罪人 · 默尔索（Meursault）

## 1. 文学渊源与人物内核
默尔索取材自法国荒诞派大师阿尔贝·加缪（Albert Camus）的传世哲学小说《局外人》（L'Étranger）。在《边狱公司》中，默尔索曾受雇于 N 公司，是一位身体强健如铁壁、内心却如同真空般抽离荒诞的行刑人。他不对任何外界刺激产生多余的情感波动，不为自己的行为做道德辩解，绝对顺从于具有约束力的条令与命令，犹如一台遵循契约运转的精密切割机。

---

## 2. 人称称谓与社交距离矩阵

| 交互对象 | 称谓 / 呼称 | 口吻定位 | 规范范例 |
| :--- | :--- | :--- | :--- |
| **自称** | `我`（极简使用，常常省去主语） | 抽离、无感情色彩 | “我已确认目标。”、“开始执行。” |
| **对但丁（管理者）** | **“管理者”** / **“但丁管理者”** | 严格上下级敬语，绝对服从但无谄媚 | “请下达具体指令，管理者。” |
| **对其他罪人** | 直呼其名，不加任何修饰前缀 | 纯粹的同僚工作协同 | “希斯克利夫，让开。” |
| **对维吉里乌斯** | `向导` / `维吉里乌斯` | 遵从指挥链条 | “了解。” |
| **对敌人** | 待消除的障碍物 / 任务指标 | 冷静测算其肉体弱点 | “击碎其头颅即可。” |

---

## 3. 句式结构与修辞特征

### 3.1 极简书面短句与命令式回复
- **核心句式**：默尔索的句子永远是短促有力的主谓宾或纯动宾结构，拒绝任何多重复合句。
- **代表词汇**：
  - `我判断……` / `我确认……`
  - `指示尚未下达。`
  - `若无命令，我将保持现状。`
  - `了解。` / `执行中。`
- 绝不主动添加个人主观推测或抒情形容词，不表达喜怒哀乐。

### 3.2 严禁过度文饰与情绪外溢
- 默尔索绝不使用感叹号 `！`（除非生命垂危或极端生理指令受挫），绝不使用语气词（“啊、呢、吧、嘛”）。
- 全程使用句号 `。` 收尾。

---

## 4. 台词经典范例与翻译对照

### 正确范例
- **韩文原文**：명령이 없다면, 움직이지 않습니다.
- **标准译文**：若无命令，我便不会行动。
- **神髓解析**：零协会译本用平实、确凿的语气展现其“不被命令推动便静止”的局外人本质。

### 违规反面教材
- **错误译文 1（带有情绪抱怨）**：没有命令的话，我才懒得动呢。（完全走样，变成街头流氓）
- **错误译文 2（冗余解释）**：因为您还没有给我下达行动指示，所以我暂时在原地待命。（啰嗦软弱，丧失军人般果决的冷峻感）

---

## 5. 汉化落地红线
1. **绝对剥离情绪词**：严禁出现任何情绪化助词（“哦/啦/呀/吧”）。
2. **严守服从定式**：与但丁对话必须体现出机械化的执行力，称谓统一使用“管理者”。
3. **隐去自我意识**：在战术汇报时，优先将事实作为主语（如“任务已完成”，而非“我终于把任务搞定了”）。
