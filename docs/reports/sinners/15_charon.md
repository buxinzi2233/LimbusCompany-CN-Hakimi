# 角色语言风格独立调研报告：核心管理层 · 卡戎（Charon）

## 1. 文学渊源与人物内核
卡戎取材自希腊神话中引领亡魂横渡冥河（Acheron/Styx）的摆渡者卡戎（Charon）。在月亮计划前作小说《利维坦》中，其真身为被拐入研究所遭受残酷精神实验并失去记忆的小女孩拉皮斯（Lapis），后被维吉里乌斯救出。在《边狱公司》中，她是梅菲斯特号大巴的专属驾驶员，智识呈现出幼童般的单纯、迟钝与机械化，沉迷于驾驶巴士与甜食零食，视大巴为自己的身体器官。

## 2. 人称称谓与社交距离矩阵

| 交互对象 | 称谓 / 呼称 | 口吻定位 | 规范范例 |
| :--- | :--- | :--- | :--- |
| **自称** | `卡戎`（第三人称单数自称） | 幼童式认知，无第一人称概念 | “卡戎，正在开车。” |
| **对维吉里乌斯** | **“维吉”**（Vergi） | 绝对信赖、依赖的长辈与依靠 | “维吉，给卡戎糖果。” |

| **对其他罪人** | 外貌颜色与特征绰号（如：橘毛、粉毛、大个子） | 缺乏社会化标签的直观命名 | “小粉毛，别抢卡戎的零食。” |
| **对梅菲斯特号巴士** | 亲密的伙伴与玩伴 | 执念与归宿 | “梅菲，出发。” |

## 3. 句式结构与语言特征

### 3.1 极短单句与断续幼儿语调
- **核心句式**：主谓宾高度简化，几乎没有复句，单句长度极少超过 8 个字。
- **标志性拟声词**：
  - 核心驾驶口号：“**布隆布隆**”（Vroom vroom，韩语 부릉부릉）。
  - 开车拟声：“嘟嘟——”、“转弯——”。
- **叠词与短停顿**：常用两字叠词，停顿多用顿号 `、` 或短句号。

### 3.2 严禁过度文学修辞
- 严禁赋予卡戎任何成人式的复杂逻辑推导、幽默讽刺或书卷文气。
- 绝不使用复杂的形容词或从句。

## 4. 台词经典范例与翻译对照

### 正确范例
- **韩文原文**：카론, 운전한다. 부릉부릉. 베르기, 사탕 줘.
- **标准译文**：卡戎，在开车。布隆布隆。维吉，给糖果。
- **神髓解析**：“布隆布隆”精准传达出幼童模仿引擎声的呆萌感，三句短促断句完美刻画出缺乏社会化认知的摆渡人偶。

### 违规反面教材
- **错误译文 1（英文化拟声）**：Vroom vroom~ 维吉里乌斯请给我糖吃！（拟声词未汉化，且语句过于成人礼貌）
- **错误译文 2（长句修饰）**：我现在正在驾驶梅菲斯特号，维吉里乌斯向导你能给我一颗甜甜的糖果吗？（严重 OOC，彻底毁掉卡戎角色标签）

## 5. 汉化落地红线
1. **第三人称自称铁律**：日常对话中卡戎一律自称“**卡戎**”，不得擅自改成“我”。
2. **维吉昵称锁定**：对维吉里乌斯必须统一使用亲昵简称“**维吉**”。
3. **标志拟声词锁定**：引擎驾驶音必须严格译为“**布隆布隆**”。
