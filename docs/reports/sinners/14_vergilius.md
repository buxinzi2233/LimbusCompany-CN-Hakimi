# 角色语言风格独立调研报告：核心管理层 · 维吉里乌斯（Vergilius）

## 1. 文学渊源与人物内核
维吉里乌斯取材于古罗马帝国最伟大的诗人普布利乌斯·维吉里乌斯·马罗（Publius Vergilius Maro），亦即《神曲·地狱篇》中受贝雅特丽齐之托引领但丁游历地狱的智者与向导。在月亮计划世界观中，维吉里乌斯是前作小说《利维坦》（Leviathan）的男主角，都市巅峰武力——“**猩红视线**”（Red Gaze），现作为梅菲斯特号巴士的向导与战斗护航者。他背负着孤儿院覆灭与失去挚爱养子的沉重过往，神情冷酷阴郁，散发着令人窒息的血海压迫感。

## 2. 人称称谓与社交距离矩阵

| 交互对象 | 称谓 / 呼称 | 口吻定位 | 规范范例 |
| :--- | :--- | :--- | :--- |
| **自称** | `我` | 冷漠、压迫感十足、抽离 | “我不会再说第二遍。” |
| **对但丁（管理者）** | **“管理者”** / **“但丁经理”** | 恪守雇佣契约，略带居高临下的敲打 | “但丁经理，请管好你手下这帮杂耍演员。” |
| **对浮士德** | **“浮士德女士”** | 少数能够进行平级智力对话的尊重 | “浮士德女士，路线规划是否有变？” |
| **对卡戎** | 极其罕见的微弱温和与长辈式纵容 | 唯一残存的人性温情寄托 | “卡戎，慢慢开，别急。” |
| **对罪人群体** | 蔑称为 `这群家伙`、`杂耍团`、`蠢货` | 极度厌烦、无聊与居高临下的武力震慑 | “再吵闹一句，我不介意替但丁提前清理车厢。” |

## 3. 句式结构与修辞特征

### 3.1 疲倦叹息与致命威慑
- **标志性前缀**：长叹气“哈啊……”、“呼……”，表现出对世俗争执的极端厌烦。
- **语势特征**：低沉、平稳、语速缓慢却字字如千钧巨石。绝无废话，通常一句话即可彻底终结车厢内部的所有混乱争吵。
- **黑色幽默与冷嘲热讽**：善于用极其平静的语调描述最血腥的残杀与后果。

### 3.2 标点符号规范
- 维吉里乌斯的台词中极少使用惊叹号，他的威慑力来自于冷酷的句号 `。` 与令人不寒而栗的破折号 `——`。

---

## 4. 台词经典范例与翻译对照

### 正确范例
- **韩文原文**：하아…… 단테 관리자. 당신의 장난감들이 또 선을 넘으려 하는군요.
- **标准译文**：哈啊……但丁经理。你的这群玩具似乎又打算越界了呢。
- **神髓解析**：“哈啊……”的疲惫与“玩具”的冷酷蔑视，将五阶特色收尾人凌驾于众生之上的绝对压迫感刻画得淋漓尽致。

### 违规反面教材
- **错误译文 1（暴躁咆哮）**：喂！你们这帮混蛋别给老子闹事了，烦死了！（完全沦为街头混混，丧失特色收尾人的宗师威严）
- **错误译文 2（尊崇下属）**：尊敬的但丁管理者，请问需要我为您排忧解难吗？（彻底走样）

## 5. 汉化落地红线
1. **向导威严不可动摇**：对罪人必须维持绝对上位者的冷峻质感。
2. **叹气词规范**：叹息统一使用“哈啊……”配合六点省略号。
3. **卡戎专属温和**：对卡戎说话时语调必须明显柔化，展现原著《利维坦》的情感继承。
