# 角色语言风格独立调研报告：03 号罪人 · 堂吉诃德（Don Quixote）

## 1. 文学渊源与人物内核
堂吉诃德取材自西班牙作家塞万提斯的讽刺文学丰碑《堂吉诃德》（Don Quixote de la Mancha）。在游戏中，她是狂热的收尾人迷妹与“正义骑士”，言行充满游侠骑士文学的戏剧化夸张与浪漫幻想。在第七章揭示其二代血鬼始祖（桑丘）的真实身份后，其语言在“热血逗比骑士”与“冷峻古老血裔”之间展现出极具张力的反差。

---

## 2. 人称称谓与社交距离矩阵

| 交互对象 | 称谓 / 呼称 | 口吻定位 | 规范范例 |
| :--- | :--- | :--- | :--- |
| **自称** | **“吾”**（日常游侠状态） / **“我”**（桑丘觉醒冷酷状态） | 华丽复古骑士腔 | “吾乃正义之收尾人，堂吉诃德！” |
| **对他人（单数）** | **“汝”** / **“卿”** | 中世纪游侠骑士对平民或同袍之称 | “汝可有何冤屈待申？！” |
| **对同伴（复数）** | **“汝等”** / **“同袍们”** | 并肩作战的骑士战团感 | “汝等且看好吾之长枪！” |
| **对但丁（管理者）** | **“但丁老爷”**（Dante-Nari / 나리） | 封建家臣/骑士对其主君领主的极致敬畏 | “但丁老爷！请赐予吾冲锋之准许！” |
| **对维吉里乌斯** | **“维吉里乌斯老爷”** | 对长官的高阶敬称 | “维吉里乌斯老爷，不可纵容恶徒啊！” |
| **对希斯克利夫** | `希斯克利夫先生` | 正式礼貌的绅士骑士称谓 | “希斯克利夫先生，莫要粗鲁！” |
| **对辛克莱** | 直呼其名 `辛克莱` | 亲昵的同龄骑士见习感 | “辛克莱！同吾一同冲锋！” |

## 3. 句式结构与修辞特征

### 3.1 戏剧化腔调与高密度感叹
- **情感充沛**：句末频繁使用感叹号 `！` 或感叹连击 `！！`，声音嘹亮、语速极快。
- **古雅词汇密集**：使用大量骑士道词汇，如“匡扶正义”、“诛灭邪祟”、“冲锋陷阵”、“荣光”、“试炼”。
- **经典口头禅**：
  - “正义必胜！”
  - “冲啊，驽骍难得（Rocinante）！”

### 3.2 语境切换（第七章血鬼与桑丘模式）
当剧情切换到桑丘与原本的二代血鬼状态时：
- 卸下所有浮夸的感叹号与中二台词；
- 语气转为沉稳、疲惫、古老而深邃的沧桑长者腔调，此时自称回归为“我”，使用全角句号收尾。

## 4. 台词经典范例与翻译对照

### 正确范例（游侠状态）
- **韩文原文**：정의는 결코 패배하지 않는 법이오!
- **标准译文**：正义绝无落败之理！
- **神髓解析**：“……之理”精准对应韩文古式结语 `~법이오`，既有古朴骑士文采，又符合中文话剧口语。

### 违规反面教材
- **错误译文 1（现代大白话）**：正义是肯定不会输的啦！（完全沦为普通热血动漫少女，丢失塞万提斯文学风骨）
- **错误译文 2（误译但丁称呼）**：但丁经理 / 但丁大人（必须准确翻译为“**但丁老爷**”，原韩语是朝鲜封建时代的官人敬称 `나리`）。

---

## 5. 汉化落地红线
1. **主君称谓锁定**：但丁与维吉里乌斯在堂吉诃德口中**必须译为“老爷”**。
2. **人称代词古朴一致**：日常状态严禁“你/我”乱窜，必须维持“吾/汝”。
3. **坐骑鞋子双关**：其鞋子名字必须严格对照塞万提斯原著马名“**驽骍难得**”（Rocinante）。
