# 角色语言风格独立调研报告：02 号罪人 · 浮士德（Faust）

## 1. 文学渊源与人物内核
浮士德的原型源自约翰·沃尔夫冈·冯·歌德的诗剧巨作《浮士德》（Faust）。在《边狱公司》中，浮士德是梅菲斯特号巴士的研发者，同时作为“全知者”与多元世界线浮士德知识网络相连。她展现出超凡的智性、极致的理性与客观冷漠，坚信自己无所不知，以近乎机械般精准的标准德语/学院派口吻与世界对话。

---

## 2. 人称称谓与社交距离矩阵

| 交互对象 | 称谓 / 呼称 | 口吻定位 | 规范翻译例句 |
| :--- | :--- | :--- | :--- |
| **自称** | **“浮士德”**（第三人称绝对自称） | 自矜、抽离、绝对自信 | “浮士德不会犯错。”、“这在浮士德的推演之中。” |
| **对但丁（管理者）** | `但丁先生` / `管理者但丁` | 职场首席顾问式平视与专业辅佐 | “但丁先生，请下达复活指令。” |
| **对男性罪人/NPC** | `某某先生`（如：辛克莱先生、格里高尔先生） | 严格恪守礼节的学术社交界限 | “默尔索先生，请执行该步骤。” |
| **对女性罪人/NPC** | `某某小姐`（如：以实玛利小姐、罗佳小姐） | 客观规范的女性称谓 | “良秀小姐，请收敛您的行为。” |
| **对维吉里乌斯** | `维吉里乌斯先生` | 平级专业合作关系 | “如您所见，车辆引擎运转正常。” |
| **对但丁钟表声转述** | 中性代词：`其/此/该`、客观转述 | 避免代入主观情绪 | “管理者的意思是，我们需要折返。” |

## 3. 句式结构与语言风格特征

### 3.1 第三人称自称铁律
- **最高准则**：在任何常规对话、战术汇报、理论推导中，浮士德**极少使用第一人称“我”**，一律自称“浮士德”。
- 只有在极度受挫或精神动摇的极其罕见情境下，才可能微弱流露出第一人称，汉化时不可轻易代换。

### 3.2 严密的学术报告体与因果逻辑
- **词汇选用**：大量使用书面化科学技术词汇、概率术语与逻辑连接词（如：“由此推断……”、“从概率学角度而言……”、“此假说并不成立……”）。
- **情绪控制**：没有惊叹句，几乎不使用波浪号 `~`，语气永远波澜不惊，即使面对生死危局依然像在宣读实验数据。

## 4. 台词经典范例与翻译对照

### 正确范例
- **韩文原文**：파우스트는 모든 것을 알고 있습니다.
- **标准译文**：浮士德无所不知。
- **神髓解析**：干脆利落的第三人称断言，展现全知者的自信与冷傲。

### 违规反面教材
- **错误译文 1（丢弃第三人称）**：我什么都知道。（泯然众人，彻底抹杀浮士德角色标签）
- **错误译文 2（过于热情口语）**：放心吧大家，我全都搞得清清楚楚呢！（严重崩坏，直接 OOC 变成知心大姐）

---

## 5. 汉化落地红线
1. **严禁“我”字泛滥**：只要韩文原文是以 `파우스트는`（Faust is/does）展开，中文必须严格保持“浮士德”。
2. **严禁省略“先生 / 小姐”**：浮士德对全体同僚的人称必须带有尊称后缀，体现其刻意保持的理性距离。
3. **句式严禁情感化助词**：禁用“呀、呢、哇、哦”等情绪软化词。
