# 角色语言风格独立调研报告：01 号罪人 · 李箱（Yi Sang）

## 1. 文学渊源与人物内核
李箱的原型为韩国现代主义文学先锋金海卿（笔名李箱，1910–1937），其代表作包括《翼》《乌瞰图》《蜘蛛会蜘蛛》等。在《边狱公司》中，李箱曾是九人会的核心研究者，性格沉郁内敛、知性孤僻，背负着过往的理想幻灭与朋辈决裂之痛。他的语言带有浓厚的 20 世纪初东方近现代知识分子文人腔调，既有旧时代的书卷儒雅，又带着存在主义式的疏离沉思。

## 2. 人称称谓与社交距离矩阵

| 交互对象 | 称谓 / 呼称 | 口吻定位 | 范例表达 |
| :--- | :--- | :--- | :--- |
| **自称** | `我` / `鄙人`（极少书面公文） | 平静自持，不傲慢亦不自卑 | “我早已习惯这般孤寂。” |
| **对但丁（管理者）** | `但丁` / `管理者但丁` | 偏白话的尊重，不卑不亢的同僚感 | “但丁，这般抉择是否略显仓促？” |
| **对女性罪人** | `某某女士`（如：浮士德女士、奥提斯女士） | 旧式绅士礼貌，克制界限感 | “浮士德女士所言甚是。” |
| **对男性罪人** | 直呼其名（如：辛克莱、格里高尔、默尔索） | 带有同伴关切的平视 | “辛克莱，莫要慌乱。” |
| **对维吉里乌斯** | `维吉里乌斯` / `向导` | 恪守职责的中立态度 | “向导的指示，我已知晓。” |
| **对敌人 / 异想体** | 平静审视，不带仇恨攻击性 | 超然的观察者视角 | “这般造物，亦是某种心境的映射么。” |

## 3. 句式结构与语言风格特征

### 3.1 旧式文人白话，非生硬半文言
- **核心风格**：白话为主，辅以雅致的书面语汇。李箱的谈吐绝不是故作高深的古装剧文言文（避免滥用“尔等”“甚好”“此乃何物”），而是五四/日治时期受过高等教育的新文人白话。
- **代表句式**：
  - 惯用“我已知晓”（而非“我明白了”或“收到”）。
  - 偏好感叹沉思句尾：“……吗。”、“……亦无不可。”、“……罢了。”
  - 多用转折与内省连接词：“诚然……”、“固然如此……”、“若真如此……”

### 3.2 语速平缓，留白深远
李箱极少使用感叹号 `！`，多使用平稳的句号 `。` 与六点省略号 `……`。情绪激荡时，其语言往往更加冷峻和隐晦，表现为意象化的诗意自语。

## 4. 台词经典范例与翻译对照

### 正确范例
- **韩文原文**：그대, 날개의 깃을 온전히 펼칠 수 있는가.
- **标准译文**：你，尚能完好地展开羽翼之翎羽吗？
- **神髓解析**：“翎羽”与“羽翼”呼应其核心小说《翼》的主题，用词清隽典雅。

### 违规反面教材
- **错误译文 1（过度古风）**：尔可能展其金翅翱翔乎？（严重偏离，变成仙侠文风）
- **错误译文 2（过度口语）**：你还能不能好好把翅膀张开啊？（彻底丧失文人学者气质）

## 5. 汉化落地红线
1. **严禁武侠/仙侠黑话**：不要把李箱写成古装剑客，他本质是近现代实验文学家与镜像技术科学家。
2. **女性统一尊称“女士”**：在剧情中称呼浮士德、罗佳、以实玛利、奥提斯等时，必须使用“女士”。
3. **“我已知晓”定式**：当韩文表达认知确认时，统一使用“我已知晓”。
