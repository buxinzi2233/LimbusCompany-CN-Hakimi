# 角色语言风格独立调研报告：04 号罪人 · 良秀（Ryōshū）

## 1. 文学渊源与人物内核
良秀取材于日本文豪芥川龙之介的经典短篇《地狱变》（Hell Screen）中的画师良秀。在《边狱公司》中，她是嗜烟如命、奉“暴力为至高艺术”的冷酷刀客，腰佩未出鞘的妖刀，性格桀骜不驯、极度危险。其核心心理在于将杀戮与痛苦升华为美学构图，对世俗礼法规矩嗤之以鼻。

---

## 2. 人称称谓与社交距离矩阵

| 交互对象 | 称谓 / 呼称 | 口吻定位 | 规范范例 |
| :--- | :--- | :--- | :--- |
| **自称** | `我`（极少使用，多省略主语） | 傲慢、冷眼旁观 | “啧。别挡着我的视线。” |
| **对但丁（管理者）** | 直呼 `钟表头`（Clockhead） / `但丁` | 毫不尊重的蔑称与调侃 | “喂，钟表头。倒转发条。” |
| **对其他全体罪人** | 极少叫名字，多用短促代词或特征蔑称 | 视作不通艺术的凡夫俗子 | “啧，吵死了。” |
| **对辛克莱** | 特殊互动对象（良秀的缩写解读者） | 略带玩味的工具人 | “小鬼，跟上。” |
| **对敌人 / 猎物** | 艺术画卷上的素材 / 颜料 | 纯粹的剥制与解构欲 | “骨肉分离的线条……还不坏。” |

## 3. 语言风格与独门缩写机制

### 3.1 招牌语言机制：四字汉字点式缩写
良秀拥有整个游戏中最标志性的言语特征——**将一整句复杂长句浓缩为带间隔号的四字（或三字/五字）短语**：
- **符号排版规范**：汉字之间必须使用全角中圆点 `·` 隔开。
- **经典零协会对照词库**：
  - `除·缩·没·想` -> 除了缩写就没别的想说的了吗？
  - `寸·铁·杀·人` -> 用最简短利落的手段致命。
  - `画·龙·点·睛` -> 给予最终致命一击完成构图。
  - `血·肉·模·糊` -> 对屠宰现场的艺术赞美。

### 3.2 语势短促、冷冽如刀
- 良秀的话语极少超过 15 个字，断句干脆，常用单音拟声词（如：`啧。`、`嗤。`、`呵。`）。
- 绝不使用任何敬语、长辈尊称或社交客套话。

---

## 4. 台词经典范例与翻译对照

### 正确范例
- **韩文原文**：예·아·모（예술도 아주 모르는 것들이）
- **标准译文**：不·懂·艺·术。（一群完全不懂艺术的蠢货。）
- **神髓解析**：零协会将韩文首字缩写精准转译为符合中文四字成语/成句习惯的结构，由辛克莱在后文进行解包说明。

### 违规反面教材
- **错误译文 1（丢失缩写）**：你们真是一群完全不懂艺术的蠢货。（完全丧失良秀特色，沦为平庸路人）
- **错误译文 2（符号错误）**：不.懂.艺.术 或 不-懂-艺-术（严禁使用英文半角句点或减号，必须是中文间隔号 `·`）。

---

## 5. 汉化落地红线
1. **缩写格式铁律**：所有缩写词中间必须且只能使用全角间隔号 `·`，不得使用空格或西文点。
2. **绝对禁止敬语**：无论面对但丁还是维吉里乌斯，良秀台词中绝不可出现“请”、“您”等谦敬词。
3. **艺术与刃的隐喻**：描述战斗时优先采用美术与画作隐喻（“构图”、“着色”、“剪裁”、“线条”）。
