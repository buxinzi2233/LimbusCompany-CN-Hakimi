## 4. 世界观名词与既定处理核查

1. **成年模型 `뷔페어른`（布菲）与幼年模型 `뷔페어린이`（普伊）**：
   - 幼年期模型 `뷔페어린이` 在剧情和 RPG 中一律准确称呼为“普伊”；
   - 成年模型 `뷔페어른` 译为“布菲”；
   - `S1029B` 揭名前的 teller 字段精准保持遮蔽覆盖（显示为 `普伊？`），直到第 11 句自白揭名（“布菲……叫我布菲就足够了。”）后李箱与默尔索才改称“布菲”，未擅自提前揭示。
2. **黄金之茧“扭扭”（꼬물이）**：
   - 全文本 29 处涉及普伊为黄金之茧命名的对白中，统一为“扭扭”；相关动作“꿈틀거리다”准确译为“蠕动”，词汇与情感基调高度一致。
3. **“勒内昂”（르네앙 / Le Néant）与“解构主义/派”（해체주의）**：
   - 勒内昂（百货裂隙后诞生的虚无存在）与解构派/解构主义严格区分，未发生混淆；
   - 势力阵营红派（르루주 / Le Rouge）、黑派（르누아르 / Le Noir）、褐派（르카키 / Le Khaki）清晰划分，无混同错误。
4. **S1028B id=20 原文省略主语与实事求是原则**：
   - 韩文原文为：`고치가 아파해서… 같이 아파하는 것 같아.`
   - 既往译文强行增补了代词主语“它”，并主观脑补了“在喊痛”与“痛苦地悲鸣”。
   - 现已彻底修复，恢复省略主语的自然童声口吻：“茧觉得很痛……所以好像也一起觉得痛。”

## 5. 确凿发现并精确修正的问题清单

### 修正 1：`StoryData/S1028B.json` (id: 20)
- **韩文原文**：
  ```json
  "content": "고치가 아파해서… 같이 아파하는 것 같아."
  ```
- **原中文译文**：
  ```json
  "content": "茧在喊痛……所以它好像也在一起痛苦地悲鸣。"
  ```
- **修正后译文**：
  ```json
  "content": "茧觉得很痛……所以好像也一起觉得痛。"
  ```
- **修正理由**：
  - 说话人为普伊（幼年布菲）。原文韩文直译为“因为茧觉得很痛……所以好像也一起觉得痛”。
  - 原译文强行增补了代词主语“它”，且过度脑补添加了“在喊痛”和“痛苦地悲鸣”。
  - 修正后严格遵循铁律要求“保留 S1028B id20 原文省略主语的处理，不强行增补主语”，贴合儿童口吻。
