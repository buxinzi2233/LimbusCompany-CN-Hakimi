# 都市零协会汉化规范调研报告（二）：命名存档体系与术语库研报

## 1. 调研背景与命名存档（Name Archive）演进
在《边狱公司》（Limbus Company）的汉化迭代中，早期分散的术语表已正式升级重构为“**命名存档**”（Name Archive）。该体系承载着整个月亮计划世界观的专有名词体系，是保证所有汉化组员、审校与外部协同统一技术语言的“单一事实来源”（Single Source of Truth, SSOT）。

本研报旨在对齐零协会命名存档库，系统梳理人物/人格、E.G.O、异想体、组织阵营、战斗状态等核心术语与翻译映射逻辑，杜绝新赛季文本中出现“一词多译”或“设定偏差”。

### 2.2 都市势力与组织阵营命名规范
都市组织命名严格遵循“翼”、“协会”、“指”、“事务所”的层级结构：
1. **翼（Megacorporation）**：
   - `L公司`（Lobotomy Corporation）：脑叶公司。
   - `K公司`：韩语汉字词“摘除”（K-Corp），下属部队统一译为“**K公司3级摘除人员**”。
   - `T公司`：时间征收（Time），科技为“时间延缓/保存”。
   - `W公司`：跃迁（Warp），下属部队为“**W公司清理要员**”。
2. **协会（Associations）**：
   - 严格按西班牙语序数词命名：
     - 一协会（Hana）、二协会（Zwei）、三协会（Tres）、四协会（Shi）、五协会（Cinq）、六协会（Liu）、七协会（Sept）、八协会（Ocho）、九协会（Devyat）、十协会（Dieci）、十一协会（Once）、十二协会（Doce）。
   - 中文统一格式：`X协会`，如 `六协会南部分科4科`。
3. **手指（The Fingers）**：
   - `拇指`（Thumb）：严酷阶级与枪械礼仪。
   - `食指`（Index）：指令（Prescript）执行。
   - `中指`（Middle）：义气、复仇账本与纹身。
   - `无名指`（Ring）：艺术暴力美学。
   - `小指`（Pinky）：潜行暗杀。
4. **特色收尾人（Color Fixers）**：
   - `붉은시선` -> **猩红视线**（Vergilius）
   - `검은침묵` -> **漆黑苦难** / **漆黑噤默**（Black Silence，历史前作继承词）
   - `보랏빛눈물` -> **紫罗兰之泪** / **紫珀之泪**（Purple Tear）

### 2.3 异常与 E.G.O 命名体系
E.G.O 命名必须紧扣文学出处与原版语义，杜绝机翻：
- `홍염살`（Hongyeom-sal） -> **红艳煞**（命理八字煞星，不可直译为“红炎杀”）
- `소망석` -> **希冀之石**
- `다시보는그날` -> **重温昔日**
- `평생주방` -> **一生炖菜**（罗佳 E.G.O）
- `초롱` -> **肉食提灯**
- `검은줄기` -> **墨黑枝干**
- `눈물로벼린칼` -> **泪水淬成之刃**

## 3. 命名存档的协同与扩展流程
1. **查重第一原则**：新赛季遇到新人物、异想体或技能名，必须先在 `archive/main` 与本术语库中检索，确认无重名或同系列前例。
2. **音译与意译界限**：
   - 西方人物/神话背景优先采用新华社《世界人名翻译大辞典》标准音译；
   - 东方意象（如九人会、剑契、黑云会）严格依据汉字源流（Hanja）溯源还原。
