# 罪人异想体观察记录风格调研（一）：结构总览与全角色代号/昵称映射全表

## 1. 异想体观察记录（Abnormality Observation Log）机制与叙事功能
在《边狱公司》中，异想体（Abnormalities）的战斗数据与机制并不是直接向玩家完整展现的，而是随着罪人们在镜宫与主线中与异想体的多次交手，逐级解锁（Lv0 -> Lv1 -> Lv2 等）。这些记录不仅承担着向玩家揭示战斗机制、物理抗性、罪孽弱点与特殊被动技能的功能，更是展现各位罪人在极限战况下思维模型与性格内核的绝佳窗口。

不同罪人撰写的观察记录在格式排版、文风语气、观察切入点乃至结尾格式上均有极其严苛的定式规范，汉化时必须分毫不差地予以还原。

## 3. 四大核心观察员的风格指纹速览

在边狱公司现行文本库中，承担绝大多数正式技术战报撰写的是以下四位罪人，各具独特的“风格指纹”：

1. **李箱（Yi Sang）**：
   - 指纹：古典抒情散文诗式观察，聚焦异想体的形态美感与心理投射。
   - 标志结语：`以上，结束报告。` / `以上，报告终止。`
2. **浮士德（Faust）**：
   - 指纹：学术严谨、层次分明的等级递进体（Lv0/Lv1/Lv2），大量援引公司守则与概率学推导。
   - 标志结语：`附记：浮士德的补充说明……`
3. **默尔索（Meursault）**：
   - 指纹：极致简短的事实白描，每条战术结论强制以缩进短横杠 `- ` 起笔，不含任何修辞。
   - 标志结语：`结论如上。`
4. **奥提斯（Outis）**：
   - 指纹：标准的现代特种作战战后复盘（AAR），精确记录交火时间与战损，结尾必向但丁进行忠诚宣誓。
   - 标志结语：`以上战术评估呈报管理者大人。愿管理者大人的荣光常驻！`

后续各分篇报告将逐一深入解构这四位观察员的文本模板与排版红线。
