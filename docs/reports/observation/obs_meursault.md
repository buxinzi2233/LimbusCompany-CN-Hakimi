# 罪人异想体观察记录风格调研（四）：默尔索观察记录格式与排版规范

## 1. 文本调性与加缪式荒诞白描
默尔索的观察记录是所有罪人中最具“物理事实感”与“反修辞性”的文献。加缪《局外人》中那种毫无情感偏向、纯粹记录外界物理事实的白描手法在此达到了极致。他既不分析异想体为何悲伤，也不探讨其诞生的哲学隐喻，只记录：它有多硬、打哪里会流血、挥击间隔几秒、怎样做才能让它停止行动。

---

## 2. 标志性排版规约：短横杠条目化清单（铁律）

### 2.1 强制缩进与破折号条目
默尔索的观察记录具有全游戏唯一且不可破坏的格式特征：
- **每一项观察要点必须且只能以半角短横杠 `- `（后加一个半角空格）开头**。
- 严禁写成长篇大论的散文段落，必须拆解为一条条冰冷的要点。

### 2.2 核心句式定式
- `- 目标右臂坚硬。打击效果不佳。`
- `- 头部被击碎时，行动停止 3 秒。`
- `- 躯干出现红光时，全员需后退。`
- **固定结尾句**：
  - 标准译文：`结论如上。` 或 `以上便是全部。`（韩文原文：`이상이다.`）

## 3. 经典实机案例与翻译对照

### 实机案例：默尔索观察要点实录
- **韩文原文**：
  - 표적의 외피는 참격에 취약함.
  - 관통 공격 시 반탄력이 발생하므로 주의를 요함.
  - 관리자의 지시가 있을 시 즉각 부위 파괴를 실행할 것.
  이상이다.
- **标准中文译文**：
  - 目标的表皮对斩击抗性脆弱。
  - 实施突刺攻击时将产生反震力，需提高警惕。
  - 若接到管理者的指示，将立即执行部位破坏。
  结论如上。

## 4. 汉化质检红线
1. **短横杠空格铁律**：条目首字符必须是英文半角短横杠加半角空格 `- `，严禁中文破折号 `——` 或圆点替代。
2. **零修辞原则**：严禁出现任何心理感受、叹词或煽情修饰（如“令人战栗的威压”等是绝对禁止的）。
3. **收尾定式**：结尾必须干净利落地以 `结论如上。` 或 `以上便是全部。` 独立成行收结。
