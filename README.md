# 《边狱公司》（Limbus Company）汉化包 - 哈基米版

本项目为《边狱公司》（Limbus Company）最新赛季（第8赛季，`a1c10p1` 莫尔索主线）提供高质量本地化汉化补丁。遵循都市零协会（LLC）技术架构、文风规范与“信”字哲学，提供**完整版**与**仅战斗辅助版**两个独立发布版本。

> **为什么提供“仅战斗辅助版”？**  
> 很多玩家非常看重《边狱公司》的主线剧情叙事与文学意境，宁愿等待官方指定/零协会精翻发布后再品味剧情；但新赛季更新后，面对机制复杂的敌方机制、新 Buff、硬币效果与被动，如果没有中文词条辅助，战斗开荒与通关异常艰难。“仅战斗辅助版”精准汉化全部战斗机制，完全不引入临时剧情翻译，让您在保留最纯正原版初见剧情的同时轻松打通战斗！

## 🚀 极简安装教程

本项目采用月亮计划游戏原生多语言系统架构，无需注入第三方 Hook DLL，稳定防封。

1. 进入本仓库的 **[Releases 页面](../../releases)**。
2. 按照您的需求下载安装包：
   - 想要完整汉化：下载 `LLC_zh-CN-Full-v*.zip`
   - 仅需战斗辅助：下载 `LLC_zh-CN-CombatOnly-v*.zip`
3. 打开 Steam，在库中右键点击 **《Limbus Company》** -> **管理** -> **浏览本地文件**，进入游戏根目录。
4. 将下载的压缩包直接解压到游戏根目录下（自动合并覆盖 `LimbusCompany_Data` 文件夹）。
5. 启动游戏即可生效！如果游戏主界面未切换，可在游戏右上角设置中将语言确认为 `LLC_zh-CN`。

## ⚠️ 版本切换与干净安装特别说明

如果您之前安装过“完整版”或其他汉化包，想要切换为**“仅战斗辅助版”**：
1. 请先打开游戏目录下的 `LimbusCompany_Data/Lang/LLC_zh-CN/` 文件夹。
2. 将其中的 `StoryData` 和 `RPGSystem` 文件夹删除或重命名（避免之前安装的旧剧情文件残留在硬盘中被游戏继续读取）。
3. 重新解压 `LLC_zh-CN-CombatOnly-v*.zip` 到游戏根目录。
4. 此时新剧情与探索对话将干净回退为官方原生语言。

## 🛠️ 质量规范与门禁保证

本项目汉化严格遵循以下工业级门禁标准：
- **动词层数严格区分**：正面层数“获得”、负面层数“施加”、数值强度一律“增加”。
- **关键字空格后置机制**：`[关键词] ` 保证游戏内词条高亮与浮窗说明 100% 触发。
- **标点符号排版**：封杀全角波浪号 `～`，全量使用半角 `~`；剧情统一使用六点省略号 `……` 与全角双引号 `“”`。
- **自动化门禁**：通过 67 项 Linter 测试、3 项完整包真实资源集成测试与 116 项静态 E2E 校验。
